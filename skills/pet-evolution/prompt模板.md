# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 模板來自 2026-09-30 第三輪（霍克、摩卡）與貓型寵物的成功提示詞。改動前先讀〈為什麼這樣寫〉。

---

## 使用方式

把 `【】` 包住的部分依企劃替換，其餘原樣送出。存成 UTF-8 文字檔，用 `--prompt-file` 送。

---

## 模板本文

```
遊戲寵物「進化對照圖」：同一條進化線的兩個階段，左右並排，左邊第一階、右邊第二階。兩階的差異要像寶可夢「小火龍 → 噴火龍」那樣巨大：體型、輪廓、比例、主色都改變，只留少數特徵讓人認得是同一隻。【有參考圖時加這句：參考圖只是第一階的舊設定。】

畫風：手遊 3D 寵物模型的成品渲染，立體、體積感強，柔和棚燈，卡通化的角色造型。不是 2D 插畫、不是描線。純灰色背景，無文字，無底座。

第一階「【一階名】」：【身分一句話，例：漁港長大的小野貓】，約兩頭身，身體圓滾滾、短腿、頭大眼大，【眼睛顏色】眼睛。毛色是【一階主色】，【一階的種子特徵，寫小、寫隱約】。【服裝與配件逐項】。【招牌道具與姿勢】。表情【一階表情】。

第二階「【二階名】」：長成【身分一句話】，體型是第一階的三倍大，身形【修長／寬厚】，約【4–5】頭身，以【動物】的身體直立站著（不是人形）。毛色轉成【二階主色】，【種子長成的樣子】。【身體結構的改變：冠羽／毛領／尾巴等】。【眼睛】變得銳利，但保留卡通角色的神采。【呆萌點】。
服裝要華麗：【服裝逐項，全部要跟主題有關】。手持【二階招牌道具——寫明是一階那件道具變成的】。姿態是【二階姿勢】。
```

---

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 開頭就點名「小火龍 → 噴火龍那樣巨大」 | 不寫的話，模型預設畫「同一隻長大」，差異不夠（第一輪前科） |
| 「約兩頭身」「三倍大」「4–5 頭身」 | 形容詞（「長大一點」「更成熟」）會被打折，**給倍數和頭身比才照做** |
| 「不是人形」 | 不寫的話，二階容易長成獸人，吃掉傳說級第三階的空間 |
| 「服裝要華麗」＋逐項列 | 第二輪寫「只留三個重點」「細節少」，裝飾被砍光。**裝飾量照企劃走** |
| 二階道具「是一階那件道具變成的」 | 伏筆要明寫因果，模型才會畫出兩件的造型關聯 |
| 「保留卡通角色的神采」＋呆萌點 | 不寫的話，二階的臉會變成寫實動物（貓第一輪前科） |
| 種子「寫小、寫隱約」 | 寫太具體，一階會提前長出二階的招牌（霍克第三輪 B 前科） |
| 不寫「細節少」「材質簡潔」 | 想拉 3D 模型感而寫了這兩句，結果連裝飾一起砍（第二輪前科） |

## 參考圖使用規則

| 情況 | 參考圖 |
|---|---|
| 模式 B 從零發想 | **不給** |
| 模式 A，一階的舊設定要大改（例：改成絨毛球雛鳥） | **不給**——參考圖會把一階拉回舊設定（霍克第二輪前科） |
| 模式 A，一階沿用舊設定、只重做二階 | 給一階舊圖，並寫「參考圖只是第一階的舊設定」 |
| 二階的舊參考圖 | **不給**——會把二階拉回舊體型，差異做不大 |

## 分支調整

- **鳥類**：「毛色」改「羽色」；一階寫「全身蓬鬆絨毛、翅膀是兩個短短的小肉翅」，二階寫「絨毛換成光滑的成鳥羽毛」
- **非動物本體（食物、器物擬人）**：頭身比、體型倍數照用，「動物的身體」改成「保留【本體】的造型特徵」
- **二階偏寫實時**：不要一直加「畫卡通一點」，改成強化呆萌點那一句
