# Boss 背景設計法則

> 規格與驗收的硬規範。`SKILL.md` 管流程，這份管「什麼叫做對」。
> 來源：魚類之書 Boss 企劃的背景段落（滄溟晶龍、墨海御主、熾影幻狐、貪財年獸），以及 2026-09-30 的首次實測。

---

## 一、兩種背景

既有企劃的 Boss 背景分成兩種，規格完全不同：

| 種類 | 用在哪 | 畫什麼 | 交付 |
|---|---|---|---|
| **A 漁場邊框** | Boss 事件期間的漁場（企劃「X 階段漁場背景」） | 只畫**畫面四邊的主題裝飾**，中央留給魚群；疊在原本的漁場底圖上 | 透明 PNG 疊層＋灰底原圖（有底圖時加預覽合成） |
| **B 表演背景** | 捕獲／彩金表演、小遊戲（企劃「捕獲表演背景」「小遊戲背景」「抽幻石表演背景」） | **滿版場景** | 16:9 滿版圖 |

既有企劃的實例：

| Boss | A 漁場邊框 | B 表演背景 |
|---|---|---|
| 滄溟晶龍 | 輻射晶礦附在螢幕邊界、色調偏冷；二階更密集 | 虛空星雲場景 |
| 墨海御主 | 邊框火焰（二階比一階強）、背景加亮 | 海底沉船甲板＋少許寶物 |
| 熾影幻狐 | — | 古代祭壇、兩側火炬、中央狐狸火影 |
| 貪財年獸 | — | 新年風格滿版襯底 |

**不歸這支**：Boss 本體（→ `boss-design`）、UI 元件（進度條、彩金欄、怒氣條、倒數數字）、底台專屬的追加需求（例：古代遺跡中央 Logo 發光——那是改既有底圖，不是新畫一張）。

---

## 二、A 漁場邊框

### 1. 中央留空是最高優先

漁場中央是魚群游動、玩家射擊的區域。**畫面中央約 70% 必須完全留空**，裝飾只在四邊的邊界帶，越靠中央越稀疏。

- 提示詞把這條寫成**第一條、最高優先**（模型傾向把畫面填滿）
- `scripts/frame_alpha.py` 會量中央 70% 區域的不透明比例，**超過 5% 就重抽**

### 2. 視角跟漁場一致：正上方俯視

漁場底圖是俯視海底。邊框的裝飾要是**從上往下看**的樣子；畫成側面（例如晶柱朝畫面中央刺出、像從地面仰看）疊上去會穿幫。

### 3. 疊層式、多底台共用

企劃偏好「半透明或濾鏡感直接蓋在漁場底圖上，讓四個底台共用同一張圖」。所以：

- 邊框**不畫漁場本身**，中央是灰色，由腳本轉透明
- 要看實際效果時，用腳本的 `--preview` 疊到底圖上（底圖向使用者要，或從企劃圖取）

### 4. UI 會壓在邊框上

邊框層級在 UI 下、背景上。四個角落有玩家資訊框、下方中央有炮台與按鈕——**這些位置的裝飾會被 UI 蓋住**，不必畫得太精細，也不要把招牌元素放在那裡。

### 5. 多階段：同一套元素、加強

二階通常是「同一階段的加強版」（更密集、顏色更強、色調偏移更多）。**二階用一階定稿當參考圖**，只改密度與強度。

## 三、B 表演背景

### 1. 構圖：中央留舞台

- **畫面中央留一塊開闊的空地**給 Boss 與表演特效；主要物件放在左右兩側與後方
- **畫面下方約 1/5 保持簡潔**：進度條、彩金欄這類 UI 常疊在那裡
- 左右大致對稱（表演是置中的）

### 2. 無角色、無 UI、無文字

**Boss 本人不畫進背景**。企劃要求的「狐狸火影」「章魚躲在船裡的發亮眼睛」這類**場景化的暗示**可以畫，但是是牆上的影子、背景裡的剪影，不是本體。

### 3. 配色跟 Boss 一致

表演背景要襯 Boss。**有 `boss-design` 的定稿圖時，拿它當參考圖**，並在提示詞寫「配色與參考圖的 Boss 協調，但畫面中不要出現這隻 Boss」。

### 4. 滿版 16:9

交付就是滿版場景，不加灰邊。模型給的比例不準時，用 `boss-design/scripts/fit_canvas.py --cover` 裁切填滿。

---

## 四、畫風

- 「高營收手遊的 2D 場景美術，精緻厚塗，高飽和」（首次實測效果好）
- 既有 Boss 沒有統一畫風；**有 Boss 定稿時，背景畫風向定稿靠**
- 特效光不可畫成螢光綠或黃綠（模型固定偏誤，見 kit 的 `image-studio-共用須知.md`）

---

## 五、既有企劃不改

不修改任何既有企劃。背景段落的錯字、矛盾，列給使用者看即可。

---

## 六、驗收清單

**A 漁場邊框**
- [ ] 中央 70% 區域不透明比例 ≤ 5%（看 `frame_alpha.py` 的輸出）
- [ ] 俯視視角，沒有側面仰看的物件
- [ ] 招牌元素不在四角與下方中央（UI 會蓋住）
- [ ] 企劃的邊框元素、配色都有畫出來
- [ ] 多階段：二階是一階的加強版，元素相同

**B 表演背景**
- [ ] 16:9 滿版，1920×1080
- [ ] 中央有開闊空地、下方 1/5 簡潔
- [ ] 無 Boss 本體、無 UI、無文字（場景化的影子、剪影可以）
- [ ] 企劃的場景元素都有畫出來（例：火炬數量、影子位置）
- [ ] 配色跟 Boss 協調
