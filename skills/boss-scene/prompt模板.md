# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 兩份模板都來自 2026-09-30 首次實測的成功提示詞。

---

## 一、A 漁場邊框

```
捕魚機遊戲的「Boss 事件漁場邊框」素材，16:9 橫式畫面。

最重要的規則：畫面中央約 70% 的區域必須完全留空，保持純灰色，不可放任何物件、光點或特效——那裡是魚群游動的區域，這張圖會疊在原本的漁場底圖上。裝飾只能出現在畫面四邊的邊界帶，由邊緣往內延伸，越靠中央越稀疏。

視角：正上方俯視海底（跟漁場底圖同一個視角）。
畫風：高營收手遊的 2D 場景美術，精緻厚塗，高飽和。

主題：【Boss名】的【邊框元素，例：輻射晶礦】。
邊界帶內容：【企劃的場景元素逐條，改寫成具體外觀：材質、顏色、發光方式】；【疏密分布，例：上下兩邊較密、左右兩邊較疏；四個角落最密集】。
無文字、無 UI、無角色、無魚。

【二階加這段：】
參考圖是第一階段的邊框定稿。元素、畫風、視角完全相同，只做以下加強：【企劃的二階變化，例：礦石更密集、顏色更偏藍】。中央留空的規則不變。
```

## 二、B 表演背景

```
捕魚機遊戲 Boss【捕獲表演／彩金表演／小遊戲】的「表演背景」，16:9 橫式滿版場景。

畫面中央要留出一塊開闊的空地給 Boss 與表演特效，主要物件放在左右兩側與後方；畫面下方約五分之一保持簡潔（那裡會疊 UI）。
視角：平視略俯角的舞台構圖，左右大致對稱。
畫風：高營收手遊的 2D 場景美術，精緻厚塗，高飽和。
無文字、無 UI、無角色、無動物。

場景：【Boss名】的【場景名】。
- 【企劃的場景元素逐條：位置＋外觀＋數量】
- 配色：【企劃配色；有 Boss 定稿就寫「與參考圖的 Boss 配色協調」】

【有 Boss 定稿圖當參考時加這句：】
參考圖是這個場景的主角 Boss，用來決定配色與氣氛；畫面中不要出現這隻 Boss。
```

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 邊框的「中央留空」放第一條、寫明原因 | 模型傾向填滿畫面；寫成最高優先並給理由（魚群區）才守得住。實測中央不透明只有 0.2–1% |
| 中央「保持純灰色」 | 灰色才能被 `frame_alpha.py` 轉透明；寫「透明」模型做不到 |
| 「正上方俯視」 | 不寫的話模型畫成側面場景，疊到漁場會穿幫 |
| 表演背景「下方約五分之一保持簡潔」 | 進度條、彩金欄等 UI 常疊在下方 |
| 「無角色、無動物」＋「影子可以」由場景元素條目寫明 | 不寫會自己把 Boss 畫進去；但企劃要的火影、剪影要明寫成「牆上的影子」 |
| Boss 定稿當參考時「畫面中不要出現這隻 Boss」 | 參考圖是角色時，模型預設會把角色畫進場景 |
