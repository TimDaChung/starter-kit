## 與 cannon-art 的關係（2026-09-24 決議）

**以後一律不走 `cannon-art`。** 該 skill 暫時保留，唯一用途是與本 skill 的產出做比對。

差異重點：

- cannon-art 讓 AI 直接畫下排組合圖，層序會歪（實測翅膀壓在炮台上）；本 skill 改為程式合成，層序與素材一致性由程式保證。
- cannon-art 的階段定義是 LV1／LV1.5／LV2，且**規格裡沒有要求 LV2 繼承特效**，產出會缺特效。本 skill 用 lv0／lv1／lv2，並把「lv2 ＝ 新造型＋與 lv1 完全相同的特效」寫成最高優先規則。
- cannon-art 走 Chrome 操作平台 API；本 skill 走 image-studio 的 python client，可直接 `--remove-background`。

仍值得沿用的 cannon-art 經驗：產圖平台會**偶發異常**（扁平貼紙風、加文字、加橢圓底色卡、產出與企劃不符），對策是重抽而非改 prompt——因此每輪至少出 2 張備選。
