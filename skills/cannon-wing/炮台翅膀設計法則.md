## 一、交付物定義

單一交付物 = **一張 3×3 總覽圖**；定稿後另附**套裝 ICON**（後製、不生圖：從左下格裁，見 SKILL.md Step 9.5）。

|  | lv0 | lv1 | lv2 |
|---|---|---|---|
| **列 1 炮台** | 基礎造型 | lv0 造型＋2星特效 | 4星造型＋2星特效 |
| **列 2 翅膀** | 基礎造型 | lv0 造型＋2星特效 | 4星造型＋2星特效 |
| **列 3 套裝** | 列1＋列2 疊合 | 列1＋列2 疊合 | 列1＋列2 疊合 |

底部標籤（白色粗體，固定字串，不可改寫）：

```
lv0        lv1(lv0+2星特效)        lv2(4星造型+2星特效)
```

**背景**：中性灰。現行兩種並存——暖灰褐 `#7A6E68`（4 套）／中性灰 `#808080`（2 套）。**新作一律用暖灰褐 `#7A6E68`**，統一為準。

**輸出尺寸**：本 skill 產的是**給美術參考的示意圖**，長邊 1200–1800px 即可（見 SKILL.md〈定位〉）。參考庫的正式素材是 4252–4379px，那是美術重做後的上線規格，不是示意圖的門檻。

## 二、「翅膀」的定義

**翅膀是版位，不是形體。** 指炮台兩側的左右對稱延伸物，六套現行實例：

| 套裝 | 翅膀實體 |
|---|---|
| 靈狐神契+浮世幻尾 | 九尾狐尾 |
| 天火焰劍+金刃飛翼 | 鳳凰羽翼 |
| 智慧女神+碧影戰駒 | 兩匹戰馬 |
| 日月星輪+星海雙鯨 | 兩隻鯨魚 |
| 曜晶玄宇+青鸞霓裳 | 青鸞鳥翼 |
| 春意盎然+翩翩起舞 | 蝶翼＋藤蔓 |

任何能左右對稱展開、與炮台主題呼應的造型都成立。不要預設一定是羽翼。

## 三、構圖法則

### 視角（全系列共通）

一律**平行投影**，不可出現近大遠小的透視變形。但**視角本身不固定**，依設計決定：

- **正面視角**：參考庫 6 套皆屬此類（豎琴、虎頭、鳥居、戰車都是正面立起）。
- **俯視視角**：看到的是物件的頂面與背部。喵公爵屬此類——黑貓趴伏、抬頭望向觀者、前爪朝畫面上方伸出，炮口從兩爪之間朝上。

判準不是「哪個面朝觀者」，而是**同一張圖內只能有一個投影方向，且沒有透視變形**。

### 生物型主體的朝向

俯視作品中，生物一律**背對觀者趴伏、頭朝畫面上方**（魚群方向）。若設計讓生物回頭望向鏡頭，牠的臉在畫面上會是**上下顛倒**的——從畫面上方往下依序為：

```
口鼻（嘴、鼻） → 眼睛 → 額頭／頭頂 → 耳朵（耳尖朝畫面下方）
```

喵公爵即為此例。

**寫 prompt 時必須把這個解剖順序逐項列出。** 只寫「俯視」「看到頭頂」，模型一定會畫成一般正面朝上的臉（耳朵在上、鼻子在下）——實測第一輪就是這樣錯的。

同理，頭部裝飾的位置要用**畫面方位**描述，不要用解剖部位。說「頭頂有玫瑰」模型會放到畫面下方（因為臉是倒的，解剖學的頭頂在畫面下緣）；要說「白色口鼻部的上方、畫面最上緣」。

> ⚠️ 不要寫成「不可看到物件的頂面」——俯視作品看到的就是頂面。反過來把視角寫死成「90 度俯視」同樣是錯的，6 套參考圖都不是俯視。視角必須逐案判讀。

### 炮台（列 1）
1. **中央單體**，去背，水平置中。
2. 必須有**單一視覺焦點**——發光核心、寶石、魔法陣或角色。焦點位於構圖中上段。
3. **底部收斂**：以尖端、底座、雲霧或水流收尾，因為實裝時要接炮口圓座。不可平切。
4. 形體不限類型。現行實例涵蓋：抽象武器（天火劍）、徽章星盤（日月）、微縮場景（靈狐鳥居、春意花叢）、載具＋角色（雅典娜戰車）、圖騰（曜晶）。
5. **不要求嚴格對稱**。整體視覺左右平衡即可，中央軀幹允許不對稱細節。現行反例：春意盎然 lv0／lv1 只有一隻小鳥停在左側（lv2 才變成對稱的兩隻）；智慧女神右手持矛、左手持盾。
   —— 對稱要求只約束翅膀（列 2），不約束炮台。

### 翅膀（列 2）
1. **左右兩件分開擺放，中間留空**——這是兩個獨立素材，不是一整片。留空寬度約等於炮台寬度。
2. 展開方向**向上外側**，主軸角度約 30°–60°。
3. **左右對稱**：提示詞要求兩件鏡像對稱，由模型一次畫出兩側。示意圖容許細部的些微差異（美術重做時會鏡像），但輪廓、角度、配色要對稱。
4. 單側輪廓需有**流動感的外緣**（羽尖、尾梢、藤蔓），不可是封閉的幾何塊。

### 套裝（列 3）
1. 疊合順序：**翅膀在後層，炮台在前層**。
2. 翅膀根部被炮台主體遮蔽，不得出現懸空斷口。
3. 整體外輪廓接近橫向 16:9。
4. 由 `compose.py` 疊合在純色底上（示意圖不畫版位框，見第六節）。

## 四、精緻度標準

以下八項為驗收硬指標，6 套現行素材 8/8 全數具備。缺任一項即退件。

1. **三種對比材質並存**：硬質（鎏金、銀白、寶石、水晶）＋ 有機（羽毛、毛髮、花葉、木質、雲霧、水體）＋ 能量（發光核心、魔法陣、星塵）。單一材質視為未完成。
2. **需有高質感硬質材料作為視覺重點**——鎏金、銀白、寶石、水晶皆可，**不限定金色**。多數套裝以鎏金為主，但春意盎然 lv0 炮台由木質、白花、綠寶石構成、幾乎無金屬件，仍然成立。
3. **金屬高光**：金屬件需有明確高光帶與暗部反射，不可是平塗色塊。
4. **主體漸層**：主色採 2–3 色漸層過渡。現行實例：靈狐尾 紅→白→藍、青鸞 金→藍、春意 綠→金。
5. **邊緣外發光（rim light）**：所有素材外緣須有一圈外發光。這不是風格選擇，是功能需求——實裝背景是深藍海底，沒有外發光會糊掉。
6. **飽和度**：中高飽和。低飽和／灰調在深色場景會消失。
7. **紋樣有流動方向感**，不可呆板重複堆砌。
8. **lv1／lv2 的粒子細節**：飄浮粒子、星點、花瓣或煙霧，需有大小與透明度層次，不可均勻散佈。

### 渲染風格
手繪厚塗 ＋ 遊戲美宣質感，對標**國產手遊 SSR 時裝／立繪**等級。

**明確排除**：像素風、扁平向量、寫實照片、3D 渲染感、線稿風。

## 五、階級升級語法

### lv0 → lv1：造型完全不動，只加特效

lv1 的造型必須與 lv0 **一個像素都不差**。6/6 現行素材皆嚴守此規則。

可用的 2 星特效類型：
- 背後光暈 / 環形光圈
- 飄浮粒子、星點
- 能量流動軌跡（火焰、煙霧、水流、光帶）
- 邊緣輝光增強

### lv1 → lv2：造型改版，沿用同一套特效

lv2 的特效與 lv1 **完全相同**，變的只有造型。全系列特效只做一套。

4 星造型升級手法（6 套統計）：

| 手法 | 出現 | 實例 |
|---|---|---|
| 追加金色裝飾件 | 6/6 | 靈狐金冠、青鸞金羽甲、春意金藤框 |
| 主體放大／展開更多 | 6/6 | 全數 |
| 追加新元件 | 6/6 | 雅典娜獨角＋白翼＋貓頭鷹、靈狐燈籠、春意第二隻鳥 |
| 換色或加色 | 3/6 | 靈狐 紅白→藍白（改動最大者） |

升級幅度基準：**看得出是同一個 IP，但一眼能分辨等級不同**。靈狐把尾巴整組換色仍算合格，因為狐面、注連繩、九尾形制保留。

## 六、版位框（僅列 3）

四層結構，由外而內：

| 層 | 色值 | 說明 |
|---|---|---|
| 紫色外框 | `#7A6A85` | 最外層邊界 |
| 青綠內框 | `#64837D` | 內層安全區 |
| 紅褐中央塊 | `#895F61` | 中央區塊 |
| 底色 | `#78716B` | 圖面背景 |
| 灰色半圓 | — | 底部中央，炮口底座位置 |

> 色值取樣自 `曜晶玄宇+青鸞霓裳\3x3總覽.jpg` 列3-lv0 格，41416 點抽樣直方圖，為半透明色塊疊在灰底後的合成值。

**這幾層不是隨意的示意框，是三種尺寸上限區。** 套裝企劃頁（如「神諭樂章」）的套裝組合示意圖上有文字標註，分別為：

- **實體翅膀尺寸**
- **炮台配件最大尺寸**
- **翅膀配件最大尺寸**

也就是說，素材溢出到哪一層是有實裝意義的，不只是視覺表現。做 lv2 時如果溢出過頭，等於超出該配件的尺寸上限。

> ⚠️ 哪個顏色對應哪一項**尚未逐一確認**——示意圖上的文字被素材遮住，只讀得出有這三項。要精確對應時去看套裝頁 `2.2 套裝組合` 的示意圖原檔。

**示意圖不畫版位框**：`compose.py` 只鋪純色底。這一節是給美術與企劃對尺寸時的背景知識，不是產圖步驟。

**尺寸遞增規則仍然有效**：lv0 最小、lv1 略大、lv2 明顯更大——尺寸感隨等級遞增，這是等級差異的視覺表達之一，不可三格等大。

lv0 格可額外放下注 UI 示意（`99,999` 與 +／− 按鈕），非必要。

## 七、驗收清單

出圖後逐項勾選，任一項未過即重做。

**結構**
- [ ] 3 列 × 3 欄齊全，底部標籤文字正確
- [ ] 背景為 `#7A6E68`，長邊 1200–1800px
- [ ] 列 2 左右兩件分開、中間留空
- [ ] 列 3 疊合順序正確（翅膀在後、炮台在前），無懸空斷口

**一致性**
- [ ] lv1 造型與 lv0 完全相同，只差特效
- [ ] lv2 特效與 lv1 完全相同，只差造型
- [ ] 翅膀左右對稱（輪廓、角度、配色）
- [ ] 列 3 的炮台與翅膀，與列 1、列 2 為同一份素材（非重新生成）

**精緻度**
- [ ] 三種材質並存
- [ ] 有高質感硬質材料作為視覺重點（不限金色，見第四節第 2 條）
- [ ] 金屬件有高光與反射
- [ ] 主體有 2–3 色漸層
- [ ] 全素材有邊緣外發光
- [ ] 中高飽和度
- [ ] 粒子有大小／透明度層次
- [ ] **配色未漂移**——所有元素（造型、裝飾、吊墜、特效全算）都落在企劃指定的配色範圍內，沒有跑出企劃沒寫的色系。這是實測中最常出現的缺陷：天籟聖琴的金色特效跑成黃綠、白虎戰炮多長出紅色吊墜，兩組都中。

**版位**
- [ ] 尺寸隨等級遞增：lv0 最小、lv1 略大、lv2 明顯更大
- [ ] 炮台底部收斂，可接炮口圓座

## 八、製作流程鐵則

**AI 只畫上兩列，列 3 由程式合成。**

```
AI 一次生成 2×3 去背素材：列 1 炮台 lv0／lv1／lv2、列 2 翅膀 lv0／lv1／lv2
slice.py   → 切成 6 格
compose.py → 列 3 ＝ 列 1 ＋ 列 2 疊合（翅膀在後、炮台在前），鋪底色、加底部標籤
```

理由：6 格放在同一張圖裡生成，炮台與翅膀的風格、配色、光源才會一致；列 3 若交給 AI 重畫，必定與列 1、列 2 對不上，所以一律由程式疊合。lv1 與 lv0 同型的要求靠提示詞的階段規則達成（見 `prompt模板.md` 第 h 條），挑圖時逐格驗收。

## 九、參考圖紀律

**正式使用時**：企劃頁若已附示意圖，可以讀、也可以當參考圖。那是企劃與美術已經對過的方向，沒有理由不用。

可用的參考圖：

1. **企劃頁示意圖**（若有）。
2. **其他套裝的既有成品圖**——對齊風格、精緻度與版面基準（參考庫那 6 套 `3x3總覽.jpg`）。
3. **本流程前一步的產出**——lv0 生成後作為 lv1／lv2 的參考圖，鎖定造型一致性。

**唯一例外：能力驗證測試。**

驗證本流程的產出品質時，刻意**不讀**企劃示意圖、也不餵給 image-studio，模擬「企劃只有文字、還沒有任何圖」的最壞情境。讀了等於照抄答案，測不出真實能力。這條只在測試時成立，不是日常鐵則。
