# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 所有規則都經過實測（天籟聖琴＋樂音流羽、白虎戰炮＋虎影翼刃、喵公爵），改動前先讀〈為什麼這樣寫〉。

---

## 使用方式

把 `【】` 包住的部分依企劃替換，其餘原樣送出。分支調整見最後一節。

---

## 模板本文

```
你是一位遊戲美術設計師。請依照「A.設計指引」與「B.美術設計企劃」，繪製捕魚機遊戲的炮台與翅膀零件設計圖。

A. 設計指引：
a. 這是行動裝置捕魚機遊戲的資產設計稿（遊戲內資產，非場景插畫），部件輪廓清晰可讀。
b. 【視角區：依企劃填入，見下方「視角寫法」】
c. 中央軀幹的能量輸出口【填入輸出口是什麼，例如「中央主星芒」「方天畫戟戟尖」】指向畫面正上方，且為整座炮台的最高點，不可有其他部件高過它。
d. 中央軀幹底部要收斂成尖端或底座，不可平切（實裝時要接炮口）。
e. 「兩側展翼式結構」是左右兩件獨立部件，兩件之間必須左右鏡像對稱。
f. 中央軀幹整體視覺左右平衡即可，不要求嚴格鏡像，允許不對稱的細節。
g. 精緻度需達到高營收商業手遊「【稀有度】級」的完成度：【填入 2–3 項本案關鍵質感，例如「金屬要有厚重的鑄造感與層次分明的反光，羽毛要一片片分明、有厚度與柔軟感，寶石要通透且有切面」】。硬質材料、有機材質、能量光效三者同時清楚呈現，主體色採 2–3 色漸層，所有部件外緣有一圈外發光（rim light），中高飽和度。
h. 三個階段的規則，這是全部規則裡最重要的一條，務必嚴格遵守：
   - lv0 ＝ 基礎造型，周圍完全沒有任何特效。
   - lv1 ＝ 造型與 lv0 一模一樣（一個細節都不能改）＋ 特效。
   - lv2 ＝ 升級後的新造型 ＋ 與 lv1「完全相同」的那一整套特效。
   用一句話說：造型只有兩種（lv0 與 lv2），特效只有一套。lv1 是「舊造型＋特效」，lv2 是「新造型＋同一套特效」。
   lv2 絕對不可以只有造型升級卻把特效拿掉——lv1 有的所有特效元素，lv2 必須原封不動全部保留，只是包在升級後的造型上。
   這條規則對上排的中央軀幹、下排的兩側展翼都同樣適用。
i. 配色只用【填入企劃配色】。特效不可畫成螢光綠或黃綠色，且要通透、像發光的光線，不要畫成不透明的色塊或大片霧狀底色。
j. 不要出現死亡、鬼魂、骷髏等不祥元素。

B. 美術設計企劃：請在圖中完整呈現企劃中的所有設計。
=====以下是美術企劃=====

【中央軀幹：〈炮台名〉】
概念：【企劃 2.2.A 的「概念」】
配色：【企劃 2.2.A 的「配色」】
lv0 造型：
【企劃 2.2.A 的「描述」逐條照抄，用畫面方位改寫解剖部位】
特效（lv1、lv2 共用）：【企劃 2.2.B 的「描述」】
lv2 造型變化：
【企劃 2.2.C 逐條照抄】

【兩側展翼式結構：〈翅膀名〉】
概念：【翅膀企劃 2.2.A 的「概念」】
配色：【翅膀企劃 2.2.A 的「配色」】
lv0 造型：
【翅膀企劃 2.2.A 的「描述」逐條照抄】
特效（lv1、lv2 共用）：【翅膀企劃 2.2.B 的「描述」】
lv2 造型變化：
【翅膀企劃 2.2.C 逐條照抄】

=====以上是美術企劃=====

C. 輸出規格：
a. 請輸出「一張」圖，內含 2 列 × 3 欄、共六格，內容與排列固定如下：
   - 上排（左→右）：lv0 中央軀幹、lv1 中央軀幹、lv2 中央軀幹
   - 下排（左→右）：lv0 兩側展翼、lv1 兩側展翼、lv2 兩側展翼
b. 下排的兩側展翼式結構，左右兩件要分開擺放、中間留空，留空寬度約等於中央軀幹的寬度。不要把左右兩件連成一整片，中間也不要有任何鍊子或裝飾把兩件連起來。
c. 六格排列整齊、間距一致、每格內容置中，格與格之間留出明顯的空白間隔。
d. 上排三格彼此的尺寸比例要一致；下排三格彼此的尺寸比例也要一致。上排與下排必須使用同一個比例尺——也就是說，把下排的展翼直接疊到上排對應階段的軀幹兩側時，大小關係要剛好正確。
e. 背景為單一均勻的純色，完全乾淨平整，沒有紋理、漸層、雜點、陰影、描邊、圓形或橢圓形底色卡，也沒有任何文字、標籤、數字或邊框。
```

## 視角寫法（b 條）

視角逐案判讀，不可預設。

### 正面視角（參考庫 6 套皆屬此類）

```
b. 以正投影繪製，畫面不可出現任何透視變形——不要看到物件的頂面、底面或側面厚度，所有部件都以完全展平的正對角度呈現。
```

生物主體再加一句：`生物的頭部正面朝向觀者。`（白虎戰炮實測有效）

### 俯視視角＋生物主體（喵公爵屬此類）

**必須逐項列出解剖順序**，只寫「俯視」「看到頭頂」模型一定畫成一般正面朝上的臉：

```
b. 視角：**從正上方往下俯視，而且〈生物〉是背對觀者趴伏的**。牠的頭朝向畫面上方（遠離觀者、朝向魚群方向），身體朝畫面下方。牠向後仰起頭來望向鏡頭，因此臉在畫面上是**上下顛倒**的。
   從畫面上方往下數，依序必須是：
   （1）口鼻部——嘴巴與鼻子在最上面
   （2）兩隻眼睛
   （3）額頭與頭頂
   （4）兩隻耳朵，耳尖朝向畫面「下方」
   **這是本設計最關鍵的特徵，務必畫對。絕對不可以畫成一般的、正面朝上的臉（耳朵在上、鼻子在下）。**
   以平行投影繪製，不可出現近大遠小的透視變形。
```

## 分支調整

| 狀況 | 怎麼改 |
|---|---|
| **企劃沒有「四星造型變化」** | 刪掉 h 條的 lv2 行與 B 區的「lv2 造型變化」；C.a 改成 2 欄；標籤只出 lv0／lv1 |
| **只有炮台、沒有翅膀** | 刪掉 B 區的展翼段與 A 條 e；C.a 改成單列；`compose.py` 加 `--no-wing` |
| **稀有度非傳說** | g 條改稀有度字樣，並加「造型簡潔、裝飾量適中，不要堆砌過多華麗元素」 |
| **Q 版可愛畫風** | g 條前加「畫風為 Q 版可愛風：頭大、身體小、眼睛又大又圓，表情討喜。不要畫成寫實或華麗風」 |
| **企劃只寫「造型請見圖X」** | 純文字無解，必須讀企劃示意圖，由讀圖反推造型描述填進 B 區 |

## 為什麼這樣寫（實測前科）

- **h 條（lv2 繼承特效）**：第一版只寫「lv2 外型要看得出從 lv0 升級」，產出的 lv2 把特效全丟了。`cannon-art` 的規格也有同樣缺漏。
- **不要再往下精簡了（2026-09-24 定案）**：曾試過更激進的版本（刪掉 A.f「不要求嚴格鏡像」、合併 A.c＋A.d、把 A.e 併進 C.b、壓縮 h 條、合併 C.c），實測**精緻度沒有提升**，使用者判讀後也認為現行版本觀感較好，因此退回。
  原因是**企劃內容就佔掉 prompt 的一半**（約 30 行），規則區再怎麼砍，攤到整份上都稀釋掉了——規則區內部少了三分之一，總長度只少 9.5%。精簡的邊際效益到此為止。

- **⚠️ 提示詞的注意力是零和的——這是本檔最重要的一條。**
  實測序列（同一份天籟聖琴企劃，只改提示詞）：

  | 版本 | 精緻度 | 去背 | 特效顏色 |
  |---|---|---|---|
  | 原始版 | 好 | OK | ✗ 黃綠 |
  | 加強特效配色（g 條 8 項、i 條 3 句） | ✗ 掉了 | ✗ 失敗 | ✅ 金色 |
  | 精簡版（g 條壓成 1 段、i 條 1 句） | ✅ 回來 | ✅ 修好 | ✗ 黃綠 |

  加字去修 A 問題，就會從 B 扣。**不要靠「規則寫越多越保險」**，那是錯的方向。
  特效光暈畫得又大又不透明，正是搶注意力的副作用，連帶害去背失敗。

- **特效配色不要在提示詞裡硬拗，改用後製。**
  模型對粒子特效有強烈的螢光黃綠偏好，四組實測全中。與其花篇幅壓制（代價是精緻度），不如產圖後跑 `scripts/recolor.py` 做選擇性色相位移。
  可行的原因是**色相帶不重疊**：特效落在 hue 60–100，金色約 45、藍色在 180 以上。實測位移 33.9% 的像素，主體的白羽毛、藍寶石、金屬完全沒被動到。
  提示詞裡只要留一句輕量的「不可畫成螢光綠或黃綠色」即可，不要再加強調句。
- **形體名稱會被詞彙帶偏**：時序迴音的翅膀企劃寫「三支鐘擺構成翼骨」，產出畫成金色羽翼——「翼」字太強勢。補上「這些是細長筆直的金屬擺桿，末端各有圓形擺錘；不是羽毛、不是羽片、也不要畫成羽翼的形狀」之後一次就對。
  **凡是非羽翼形體的翅膀，都要明寫「不是什麼」。**
- **C.e（禁底色卡）**：實測出現過整格被加上橢圓形底色卡，去背時整個橢圓被當成主體保留。
- **C.d（同一比例尺）**：不寫的話上下排比例不一致，合成時翅膀與炮台大小對不上。
- **不要用「貼」字**：寫過「想像成先把展翼貼在牆上，再把中央軀幹貼在它前面」，整張畫風跑成貼紙（白描邊＋投影）。改用「前景／後方」的遮擋語彙。
- **裝飾位置用畫面方位、不要用解剖部位**：俯視倒轉臉的情況下寫「頭頂有玫瑰」，模型會放到畫面下緣（解剖學的頭頂在下面）。要寫「口鼻部上方、畫面最上緣」。
- **下排組合不進 prompt**：早期讓模型自己畫下排，翅膀會壓在炮台前面。改由 `compose.py` 合成後就不可能歪。
- **平台會偶發異常**：扁平貼紙風、加文字、加底色卡、產出與企劃不符。對策是重抽不是改 prompt，因此每輪 `--count` 至少 2。
