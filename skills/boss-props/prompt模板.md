# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 模板來自 2026-09-30 熾影幻狐幻石的成功提示詞。

---

## 模板本文

```
捕魚機遊戲 Boss 表演道具的「等級系列設計圖」：同一種道具的 【N】 個等級，由左至右排成一列，等級由低到高。

畫面：16:9 橫式，純灰色背景（無漸層、無地面、無文字）。【N】 件間距平均、底部對齊，每件都完整不被切到。
畫風：與參考圖的 Boss 一致（參考圖只用來決定畫風與質感，畫面中不要出現這隻 Boss）。高營收手遊的 2D 道具美術，精緻厚塗。

道具：【Boss名】的「【道具名】」——【一句話：它是什麼、在表演裡怎麼被使用】。

等級差異不能只靠換顏色，每升一級都要在上一級的基礎上「多一個看得見的新元素」，剪影也跟著變複雜：
1. 【等級1名】：【基準外觀】。
2. 【等級2名】：【顏色】，【＋新增元素】。
3. 【等級3名】：【顏色】，【沿用前一級＋新增元素】。
…
【N】. 【最高級名】：【顏色／質變】，【沿用前一級＋新增元素＋質變描述（彩虹、通透、光暈）】。
特效光不可畫成螢光綠或黃綠色。
```

**同級異形（例：同色罐子、不同罐蓋）改寫第一段：**

```
捕魚機遊戲 Boss 表演道具的「造型變化設計圖」：同一種道具的 【N】 種造型，由左至右排成一列。
【N】 件的【本體、顏色、材質】完全相同，只有【指定部位，例：罐蓋】的造型不同：
1. 【造型1】
2. 【造型2】
…
```

---

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 逐級寫「沿用前一級＋新增元素」 | 只寫「越高級越華麗」會被打折成換顏色；**列舉每一級新增什麼**，模型才會畫出累加的剪影 |
| 一個系列畫在同一張圖 | 分開生成的風格、材質、光源不會一致 |
| 仍寫「間距平均、底部對齊」 | 讓腳本好切；**大小一致由 `lineup.py --equalize` 保證**，寫進提示詞也不會照做 |
| 不寫等級名稱文字 | 模型會寫錯中文或自創 UI；名稱由腳本加 |
| Boss 定稿當參考、但「畫面中不要出現這隻 Boss」 | 參考圖是角色時，模型預設會把角色畫進去 |
