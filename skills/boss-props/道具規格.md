# Boss 表演道具規格

> 規格與驗收的硬規範。`SKILL.md` 管流程，這份管「什麼叫做對」。
> 來源：魚類之書 6 份 Boss 企劃的道具需求，以及 2026-09-30 熾影幻狐幻石的首次實測。

---

## 一、什麼算表演道具

Boss 捕獲／彩金表演裡、**玩法會用到的物件**，通常有等級或種類之分：

| Boss | 道具 | 等級／種類 |
|---|---|---|
| 熾影幻狐 | 幻石 | 灰→藍→紫→紅→彩（5 級）；企劃明寫「**顏色以外，外觀也要看得出等級差異**」 |
| 戰神賽特 | 卡諾卜罐 | 綠／藍／紫／紅／金（5 色）；同色也有不同罐蓋造型 |
| 噬魂劍魔 | 老虎機、大轉盤、小獎圈 | 金／銀／銅（3 級）；大轉盤彩／金／銀／銅（4 面） |
| 貪財年獸 | 爆竹 | — |
| 墨海御主 | 寶物 | — |
| 滄溟晶龍 | 虛空小魚 | 3 種尺寸 |

**不歸這支**：UI 欄位（彩金欄、進度條、怒氣條、倒數）、美術字、Boss 本體（→ `boss-design`）、背景（→ `boss-scene`）。

---

## 二、等級差異法則（核心）

### 1. 不能只靠換顏色：累加法

**每升一級，在上一級的基礎上多一個看得見的新元素**，剪影跟著變複雜。只換顏色的等級系列，在小尺寸、動態中很難分辨。

實測成功的階梯（熾影幻狐幻石）：

| 等級 | 新增的元素 |
|---|---|
| 灰 | 霧面、切面少的原石，不發光（基準） |
| 藍 | ＋切面與光澤＋內部小火苗 |
| 紫 | ＋金色托座包住下半部 |
| 紅 | ＋托座兩側的狐耳金飾 |
| 彩 | ＋上方狐尾弧飾＋外圍光暈，內部火焰變七彩 |

可用的累加元素：切面／光澤 → 內部發光物 → 托座或外框 → 主題造型飾件（取自 Boss 的招牌部位）→ 光暈或粒子。**越高級的飾件越要呼應 Boss 本身**（幻狐的耳與尾），系列才有歸屬感。

### 2. 最高級要「質變」

最高一級不只是再多一件，要有質的不同：彩虹色、通透、帶粒子或光暈。玩家要一眼認出「中大獎了」。

### 3. 同一件道具的種類差異（非等級）

像賽特「同色罐子、不同罐蓋造型」這類**同級異形**，用同一張圖畫在一起，只改指定部位（罐蓋），其餘完全相同。

### 4. 色階慣例

企劃沒指定時，常見的由低到高：灰 → 綠 → 藍 → 紫 → 紅 → 金 → 彩。**照企劃的色階為準**。

---

## 三、畫面規格

- **一個系列畫在同一張圖**，由左至右、等級由低到高排成一列：分開生成必然風格不一致
- 16:9、純灰背景、無文字（等級名稱由 `scripts/lineup.py` 加）
- **大小交給腳本**：模型會自己把高等級畫得比較大。同時出現在盤面上的道具（例：一輪 8 顆幻石）要用 `--equalize` 統一大小；本來就有大小差（例：晶龍 3 種尺寸的小魚）才保留原尺寸
- 畫風與 **Boss 定稿**一致：拿定稿當參考圖，提示詞寫明「畫面中不要出現這隻 Boss」

---

## 四、既有企劃不改

- 企劃有寫道具規格就照企劃；**沒寫的等級差異，提出累加階梯跟使用者討論**
- 不修改企劃本身，缺漏列給使用者

---

## 五、驗收清單

- [ ] 一個系列一張圖，等級由低到高、由左至右
- [ ] **每升一級都多一個看得見的新元素**（不是只換顏色）
- [ ] 最高級有質變（彩虹／通透／光暈）
- [ ] 高級飾件呼應 Boss 的招牌部位
- [ ] 色階照企劃
- [ ] 同時上盤面的道具已用 `--equalize` 統一大小
- [ ] 等級名稱由腳本加上、字沒錯
- [ ] 灰底、畫面中沒有 Boss
