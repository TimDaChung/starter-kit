# 武具設計法則

> 規格與驗收的硬規範。`SKILL.md` 管流程，這份管「什麼叫做對」。
> 初版（2026-09-30）來源：功能之書〈武具系統〉§2.3、§2.7、§2.9、§2.10，以及 pet-evolution／boss-design 已驗證的畫面規格。**尚未用武具實測**，前科表（第六節）待第一次跑完回寫。

---

## 一、交付物定義

- **一張「武具外觀設計圖」**：單件武具（或一組，如雌雄雙劍）單獨入鏡，3/4 視角，懸浮於純灰背景
- **畫風**：3D 遊戲道具模型的成品渲染，不是 2D 插畫（見第四節）
- **背景**：純灰色，無文字、無底座、無 UI、無場景
- **尺寸**：1920×1080（16:9），由 `boss-design/scripts/fit_canvas.py` 保證；武具高約佔畫面 60%、寬不超過 70%
- **用途**：給 3D 美術建模的方向稿，不是上線素材。重點是類型、題材、招牌部位正確

**稀有度與階段：**

| 稀有度 | 階段 | 本 skill |
|---|---|---|
| 傳說 | 一張定稿，無進化、無階段 | ✅ 企劃目前只有這一級 |
| 一般～史詩 | 企劃 §2.3 只定義了框色（藍＞紫＞紅），沒有武具 | ⏳ 出現時先確認低稀有度是減料還是只換框 |

**與寵物線的差別**：武具升星只改效果數值與登場動畫（3 星以上加金閃），**外觀不變**——所以沒有兩階對照，也不用埋伏筆。

## 二、外觀原則（核心）

### 1. 一眼看出類型

塗黑成剪影也要認得出是劍、扇、弩、盾。裝飾再多，類型的基本輪廓不能被吃掉：劍要有刃與柄的比例、弩要有弩臂與弩機、盾要有盾面。

### 2. 招牌部位＝登場動畫的動作來源

企劃 §2.9 四把的登場動畫，每把都只圍繞**一個部位**做 1–2 秒的動作：

| 武具 | 招牌部位 | 登場動作 |
|---|---|---|
| 玄暝雙龍劍 | 一藍一白的雙劍本身 | 後退旋轉（藍逆時鐘、白順時鐘）→ 交叉到定位 |
| 離火飛鳳扇 | 扇面 | 左傾蓄力 → 原地旋轉一圈回定位 |
| 麒麟神機弩 | 麒麟獸首（眼與口） | 眼睛發青藍電光 → 電光沿弩臂流向外側 |
| 震威伏煞盾 | 盾面機關 | 只有神獸頭 → 盾面展開 → 兩側長出鐵鍊 |

所以外觀圖上**招牌部位要是視覺焦點**：比其他裝飾大、細節最多、放在構圖中心附近。設計時先問「登場的 1–2 秒它會怎麼動」，答不出來就不是招牌部位。

### 3. 一件武具、一個題材

比照寵物線「動物 × 一個概念」：武具是「類型 × 一個神獸或意象」（劍 × 龍、扇 × 鳳、弩 × 麒麟）。裝飾全部從這個題材長出來——龍劍上是龍首、龍鱗、雲紋、水波，不再疊第二個無關主題。

### 4. 豪氣浮誇 ≠ 堆料

企劃給雙龍劍的關鍵字是「整體豪氣浮誇感」。浮誇來自**尺度與姿態**（劍格特別寬、龍首特別大、穗帶特別長），不是來自裝飾數量。裝飾量照企劃走、不刻意減，判準是「每件都連得回題材」。

### 5. 一組多件的規則

企劃寫「兩支劍顏色不同但主題相同」「兩把巨劍 or 一粗一細」：

- 共同：類型、題材、裝飾語彙、比例節奏
- 差異：**主色**（藍／白）、粗細或長短、左右對稱的細節（龍首朝向）
- 兩件並排微交叉，各自完整可見，不互相遮擋招牌部位

### 6. 為下游預留

- **武具欄縮圖**：ICON 不另生圖，就是這張整組縮小（下游用 `pet-parts/scripts/item_icon.py` 後製）；縮到 64px 仍要認得出類型 → 招牌部位不能太細長、太靠邊
- **登場分鏡**：畫的是「完成態」；有機關的武具（盾）收合態留給分鏡第 1 格，外觀圖不畫收合態
- **3 星金閃**：金色點綴要留位置給閃點，整件金會讓金閃看不見（也是「金色只用點綴」的原因）

## 三、配色法則

- 控制在 **2–6 色**：主色大面積、次色中面積、點綴小面積
- **金色是點綴不是主色**：傳說稀有度的武具欄底色是黃、外框是彩，整件金會跟 UI 糊在一起
- **在深底上要跳得出來**：陣營戰 UI 是深棕深藍，武具的主色要跟這兩色拉開明度（深藍武具要靠高光與金邊撐）
- **灰階測試**：轉灰階後招牌部位仍是最亮或最暗的塊
- 一組多件：差異放主色，點綴色共用

## 四、畫風：3D 成品感

- 提示詞寫「手機捕魚遊戲的低面數 3D 道具模型成品渲染——塊面大而簡潔、面數少、輪廓誇張，手繪風貼圖，高飽和配色，刃口與紋路帶自發光。不是寫實 3A 質感、不是 2D 插畫、不是描線」
- **魚樂園的 3D 是低模手繪風，不是寫實**：寫「材質分明、金屬反光、寶石通透」會出 3A 寫實質感，跟線上道具對不上（第六節 2026-09-30 前科）。材質仍逐項寫，但寫成「一個主色＋邊緣一道高光，不畫細紋理」
- **氣勢寫形狀不寫形容詞**：「豪氣浮誇」沒作用；線上版的浮誇來自火焰狀翼形護手、龍首佔劍身四分之一、劍身寬度是柄的三倍——點名形狀與佔比
- **不要寫「細節少」「材質簡潔」**：會連裝飾一起砍（寵物線第二輪前科）
- ⚠️ **企劃未寫明武具是 2D 還 3D**：§2.1 美術需求表只寫「靜態＋動態(特效)」，廣宣頁稱「3D 物件」。本 skill 預設 3D 成品感；使用者明說要 2D 才換（規則見 `prompt模板.md` 第二節）

## 五、驗收清單

交付前逐條跑，逐條回報過或不過：

**類型與題材**
- [ ] 剪影：塗黑後一眼認得出武器類型
- [ ] 招牌部位：是視覺焦點，比其他裝飾大；能說出登場動畫它怎麼動
- [ ] 一件一題材：每件裝飾都連得回題材，沒有無關的第二主題
- [ ] 一組多件時：主題相同、主色不同、各自完整、不互相遮擋
- [ ] 跟既有武具不撞類型、不撞神獸（見 `參考素材索引.md`）

**企劃還原**
- [ ] 企劃（或 mini 企劃）美術需求的條目都畫出來了
- [ ] 道具敘述、美術需求、登場動畫三段講的是同一把
- [ ] 沒有自行加企劃沒寫的部件（有 live 企劃時）

**配色**
- [ ] 2–6 色，金色只做點綴
- [ ] 灰階下招牌部位仍突出
- [ ] 主色在深棕深藍底上跳得出來

**畫面規格**
- [ ] 3D 成品感，材質分明，不是 2D 插畫或描線
- [ ] 3/4 視角、整件完整入鏡、無裁切
- [ ] 純灰背景，1920×1080，無文字、無底座、無 UI、無場景
- [ ] 無人、無手、無角色、無生物本體（神獸只以裝飾出現，不是活的）
- [ ] 沒有畫成多把不同設計
