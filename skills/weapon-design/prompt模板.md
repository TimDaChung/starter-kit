# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 初版（2026-09-30）沿用 pet-evolution／boss-design 驗證過的寫法：給具體名詞與比例、不給形容詞；裝飾照企劃逐項列。**尚未用武具實測**，第一次跑完把結果回寫〈為什麼這樣寫〉與法則第六節。

---

## 使用方式

把 `【】` 包住的部分依企劃替換，其餘原樣送出。存成 UTF-8 文字檔，用 `--prompt-file` 送。

---

## 一、模板本文

```
遊戲「武具」外觀設計圖：一件「【武具名】」，【單件／一組兩件——兩件顏色不同但主題相同，造型對稱呼應】。畫面中只有這件武具，單獨懸浮在純灰色背景上，3/4 視角，整件完整入鏡、四周留白、不被裁切，畫得大而清楚。

畫風：手機捕魚遊戲的低面數 3D 道具模型成品渲染——塊面大而簡潔、面數少、輪廓誇張，貼圖是手繪風上色（顏色塊面清楚，不做細碎浮雕、不做寫實金屬刮痕），高飽和配色，刃口與紋路帶青色自發光，柔和棚燈。中國風奇幻。不是寫實 3A 質感、不是 2D 插畫、不是描線。純灰色背景，無文字、無底座、無 UI。
氣勢用形狀講：【具體名詞，例：護手做成火焰狀翼形向外張開、龍首佔劍身長度約四分之一、劍身寬度是柄的三倍】。

武器類型：【劍／扇／弩／盾／…】，【整體比例一句，例：劍身長約全長四分之三、劍格寬大】。
招牌部位：【最醒目的一個部位，例：麒麟獸首弩機／扇面／盾面中央的神獸頭】——是整件武具的視覺焦點，比其他裝飾大，細節最多。
題材：【企劃美術需求的風格關鍵字原文，例：中國風主題，劍身有龍相關的裝飾】。
材質用大色塊表現：【逐項，例：劍身玄鐵藍、護手鎏金、柄纏深藍絲繩】；每種材質一個主色＋邊緣一道高光，不畫細紋理。
配色：主色【】、次色【】、點綴【】；金色只用在邊飾與點綴，不做整件金。
造型細節：
- 【企劃美術需求逐項】
- 【一組多件時：各件的差異（顏色、粗細、左右）與共同主題】
- 【穗帶、鍊、寶石等垂掛物：寫明掛在哪】

畫面中不要有人、不要有手握持、不要有角色或生物本體；不要有文字、數字、UI；不要畫多把不同設計的武具（一組雌雄劍算一件）；不要畫場景、地面或底座。
```

## 二、畫風錨點決定規則

| 情況 | 錨點 |
|---|---|
| 預設 | 「手遊 3D 道具模型的成品渲染」＋「中國風奇幻」，純灰底。灰底是下游（`fit_canvas.py`、`icon_check.py`）的前提，不換 |
| 使用者要看「放在陣營戰 UI 上的效果」 | 另出一張暗底版：背景段改「深棕與深藍的漸層暗底，只做色調暗示，無圖案」。**暗底版不當定稿**，定稿仍是灰底 |
| 企劃有 2D 概念圖 | 概念圖只當「造型參考」（見第三節），畫風段照寫 3D；不要寫「參考圖的畫風」 |
| 使用者指定要 2D 插畫 | 企劃 §2.1 未寫明武具是 2D 還 3D（廣宣頁稱 3D 物件）；使用者明說才改，畫風段換「高營收手遊 2D 道具插畫，精緻厚塗」，其餘不動 |

## 三、參考圖白名單

| 情況 | 參考圖 |
|---|---|
| 模式 B 從零發想 | **不給** |
| 模式 A，企劃有概念圖、要照它畫 | 給概念圖，並在提示詞開頭加「參考圖是這件武具的概念草稿，造型與構件照它，畫風改為 3D 成品渲染」 |
| 模式 A，企劃概念圖與文字衝突、使用者選文字 | **不給**——參考圖與文字衝突時參考圖會贏（寵物線霍克前科） |
| 重抽、只改局部（換配色、放大招牌部位） | 給上一輪最佳候選，寫「參考圖是上一版，只改：【改動條目】，其餘維持」 |
| 其他武具的定稿（想統一風格） | **不給**——會把題材元素帶進來（龍飾跑到扇子上）。風格靠畫風段文字統一 |

## 四、為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 開頭就寫「一件」「一組兩件」 | 模型預設畫單把；一組寫在細節段會被忽略（初版預判） |
| 「3/4 視角」「整件完整入鏡、四周留白」 | 大小由 `fit_canvas.py` 保證，提示詞只要保證不被切到（boss-design 實證：寫佔比不照做） |
| 招牌部位單獨一行、寫「比其他裝飾大」 | 下游登場分鏡要圍繞它動；不點名會被裝飾平均掉 |
| 畫風寫「低面數、塊面大、手繪風貼圖、自發光」 | 第一輪（2026-09-30 玄暝雙龍劍）寫「材質分明、金屬反光、寶石通透」出來是寫實 3A 質感，Tim 回饋「風格跟魚樂園沒有很多，3D 面數要少一點」。魚樂園線上道具是高飽和、大塊面、邊緣發光的手繪風低模，要用這些名詞把模型從寫實拉回來 |
| 材質仍逐項寫，但寫成「色塊＋一道高光」 | 逐項寫是 3D 感的來源（不寫會回 2D 厚塗）；加「不畫細紋理」才不會又長出寫實刮痕 |
| 氣勢不寫形容詞，寫形狀 | 第一輪寫「豪氣浮誇」沒作用，出來偏古典收斂；線上版的浮誇來自火焰狀翼形護手與超大龍首，要點名形狀與佔比 |
| 「金色只用在邊飾與點綴」 | 傳說稀有度底色是黃，整件金會跟 UI 底色糊在一起 |
| 禁止事項放最後一段 | 放中段會被後面的描述蓋掉；「不要有手握持」尤其要在最後 |
| 不寫「細節少」「材質簡潔」 | 會連裝飾一起砍（寵物線第二輪前科） |

## 五、分支調整

- **一組兩件以上**（雌雄劍、雙鉤）：寫「兩件並排懸浮、微微交叉，各自完整」；差異寫在配色與粗細，不寫在題材
- **劍、槍、杖**（直向）：加「整件斜放約 45 度」——直立擺放時 `fit_canvas.py --height 0.6` 只佔畫面寬 22%，16:9 大半空著（第一輪前科）；斜放才撐得住畫面，線上版也是斜放
- **弓、弩、長柄**（橫向）：加「橫向構圖，整件橫放略斜」；`fit_canvas.py` 用 `--max-width 0.75`
- **盾、印、鏡**（正面看最清楚）：3/4 視角改「正面略側 15 度」，讓盾面圖案完整
- **有機關展開的武具**（企劃 §2.9 盾牌）：畫「展開後的完整型態」，初始收合態留給下游分鏡
- **扇、旗、幡**（軟質）：加「扇面／布面攤開，圖案完整可見」
