# Boss 動態／分鏡描述規範

> 適用：魚類之書 Boss 頁「3.3 Boss 動態」底下所有小節（登場、待機、攻擊、受擊、彩金表演、必殺技、被捕獲、結算動畫…），以及 `boss-demo` 步驟 6、`boss-design` mini 企劃的表演段落。
> 標竿：**噬魂劍魔**（美術依意見調整後確認可執行的版本）。對照組：熾影幻狐（舊寫法）、戰神賽特（分鏡細但待機／受擊／規則缺）。
> 一句話：**美術拿到就能做，不用回頭問企劃「多久？循環嗎？三階要不要各做一套？疊在 Boss 前面還後面？表演時能不能打？」**

---

## 一、每個小節的骨架

小標題 `### 3.3.X <名稱>(<動作代號>)`，動作代號跟 Spine 動作名對齊：待機／攻擊寫 `(move)`、被捕獲寫 `(caught)`。

**版面：每個小節一組兩欄**——左欄文字、右欄示意圖；一個小節一組，不跨小節共用。

左欄依動態類型取用下列欄位，**順序固定**，沒有的欄位不寫（不留「無」）：

| 順序 | 欄位 | 寫什麼 | 哪些動態要寫 |
|---|---|---|---|
| 1 | 觸發時機 | 什麼時候播、播幾次 | 攻擊、彩金表演、必殺技、結算 |
| 2 | 分鏡／步驟 | 編號步驟，每步「主體＋動作＋特效＋位置，秒數」 | 全部 |
| 3 | 循環／插入規則 | 循環到什麼時候、插在哪兩個動作之間、播放順序 | 待機、攻擊 |
| 4 | 階段差異 | 各階段各做一套，或共用一套 | 有多階段造型的 Boss，每個動態都要寫 |
| 5 | 同步點 | 哪一步跟血條／彩金欄／獎圈／造型更換同時發生 | 有 UI 或造型變化的表演 |
| 6 | 圖層 | 特效疊在 Boss 前或後，用 `<` 排序 | 有疊在 Boss 身上或前方的特效 |
| 7 | 碰撞與道具 | 表演期間移除碰撞區／禁止發炮／禁用哪張道具卡 | 彩金表演、必殺技、被捕獲 |
| 8 | 倒數 | Boss 事件倒數照常或暫停 | 彩金表演、必殺技 |
| 9 | 沿用與參考 | 沿用哪隻 Boss 的哪段、資產編號；參考圖 | 有就寫 |
| 10 | 詳見 | 機制與數值的章節號 | 有對應機制段落就寫 |

## 二、寫法規則

### 1. 每一步都是「主體＋可見動作＋特效＋位置，秒數」

一步一個畫面變化，**秒數寫在句尾**，用「，N秒」，不寫「預計」。

- 劍魔：「劍身畫面外飛入帶有紫色特效，1.5秒」「拔劍到一半，1秒」「向下插入原位，1秒」
- 舊（幻狐）：「魂玉震動，能量波向外綻放，預計2秒」「熾影幻狐現身」（最後一步沒秒數）

最後一步若是「結束狀態」（不是動作），可以不寫秒數，但要寫清楚停在哪：劍魔「煙霧散去時劍魔已經站在舞台上」。

### 2. 用看得見的動作與部位，不寫感覺

動詞要能直接做成 key：拔、插、揮砍、飛入、倒吸、灌回、收束、亮起、碎裂消失。主詞要點名部位或物件（頭盔窄縫、甲片縫隙、斷鏈、斷劍碎片、核心）。

- 劍魔：「魔氣自甲片縫隙逆流倒吸」「魔氣漩渦灌回鎧甲，裂痕短暫發亮後收束」
- 舊（賽特）：「有一種埃及神怒了要施展神威的感覺」「呈現『風暴能量正在寶石中蓄積』的氛圍」
- 舊（幻狐）：「尾巴自然擺動」「腳部動態自然擺動」

形容幅度用相對比較（「幅度最大」「比基準加大」），不用「自然」「感覺」「氛圍」。

### 3. 待機（move）要寫週期、各部位分工、循環終點

一段「基本動作：全程 N 秒」，底下逐部位列各自在動什麼；再寫循環到什麼時候。

- 劍魔：「基本動作：全程3秒」→「雙手拄劍立於舞台定點，身體隨呼吸節奏緩慢起伏」「斷鏈與懸浮斷劍碎片持續緩慢環繞」「頭盔窄縫的魔光隨節奏一明一暗」→「全程循環不停，直到劍魔死亡」
- 舊（幻狐）：兩行「自然擺動」，沒有週期、沒有終點
- 舊（賽特）：部位有寫，但除了「每隔三秒拋火球」之外沒有週期

### 4. 攻擊（move）要寫插在哪、多久插一次

攻擊是插在待機循環中的動作，要寫播放順序。

- 劍魔：「定期觸發，插入待機循環之間」「待機 ×2 → 攻擊 ×1 → 重複」

### 5. 階段差異每個動態都要明講

有多階段造型的 Boss，每個動態都寫「各階段一套」或「共用一套」。各做一套時用表格列差異：

```
動作 | 階段差異 | 備註
待機_一階 | 幅度、頻率與特效濃度最小（基準） | 全程循環
待機_二階 | 幅度與特效濃度加大 | 全程循環；<哪個部位>碎裂消失
待機_三階 | 幅度最大、特效蔓延至地面 | 全程循環；<哪個部位>碎裂消失，露出核心
```

- 劍魔：「三階段各一套，不互相沿用」「三階段共用一套」「全階共用同一套，不做階段差異」
- 舊：幾乎都沒寫，美術只能自己猜

差異要落到**部位**（哪一片碎掉、露出什麼），不是只寫「更強」。

### 6. 受擊回饋單獨一節，寫到技術層

四件事：做幾層、長什麼樣、多久觸發一次、技術上怎麼做（會不會打斷動作）。

- 劍魔：「只做命中閃光一層，不另做受擊動作層」「受擊全身刷紅光，三階段共用一套」「每次被擊中 3 秒刷一次」「shader／tint 層，不佔動作、不中斷任何狀態」
- 舊：沒有這一節

### 7. 多步表演：每步取一個短名

必殺技這類多步表演，每步用 2 字短名起頭，讓企劃、美術、工程講同一個詞。

- 劍魔：「預兆：畫面壓暗，魔氣自甲片縫隙逆流倒吸，1秒」→「匯聚：…，3秒」→「吞噬：…，1.5秒」→「回血：…，2秒」

彩金表演這類有示意圖的，用「分鏡N：」起頭，句尾用 `〔圖N〕` 對回右欄整張分鏡圖上的格號（見第三節）。

- 劍魔：「分鏡1：畫面壓黑標題美術字逐字播放，可依美術調整位置：劍魔受到大量傷害，1.5秒」

### 8. 同時發生的事用「同時」接在同一步，寫出同步點

UI 與造型的變化要指定落在第幾步。

- 劍魔：「同時跳寶物掉落文字…」「血條需與第 4 步同步回升一整格」「劍魔造型更換需於分鏡1預兆時執行」「彩金歸0依房內人數噴出每人一個錢袋飛向玩家…，同時標題美術字消失」
- 一步內有好幾件同時發生的事時，父項寫總秒數，子項列動作不各寫秒數（劍魔：「獎金變化演出：全演出共用3秒」底下 4 個子項）

### 9. 圖層用 `<` 排序

- 劍魔：「圖層：Boss本體<魔氣漩渦<小魚們」「紫氣漩渦特效圖層位於BOSS之上」

### 10. 表演期間的規則寫在同一節

碰撞、發炮、道具卡、倒數——表演做什麼和表演時玩家能做什麼寫在一起，不讓美術／工程翻去別章。

- 劍魔：「表演期間移除碰撞區，全程禁用冰凍卡；倒數不暫停」「表演期間移除碰撞區並禁止發炮，不會被子彈打到」「跳獲獎獎圈，此時玩家可繼續發炮」

### 11. 假表演物件要講清楚來源與行為

表演裡出現、但不是真的遊戲物件的東西，寫從哪生成、會不會被打、最後去哪。

- 劍魔：「吞噬用的小魚為假表演：從畫面外隨機生成〈小魚清單〉，不會被玩家擊中，到魔氣中心時表演被捕獲吸進魔氣漩渦」

### 12. 沿用與參考分開寫

- **沿用**＝直接拿既有資產或規格，寫出處（Boss 名＋段落、或資產編號）：劍魔「表演順序沿用《噬炎魔龍》」「老虎機錢袋：可直接使用 WID：〈編號〉」
- **參考**＝只借感覺，美術可以改：劍魔「寶物掉落：可參考魔龍」
- 機制與數值不寫在動態節，用「詳見 4.x」指過去：劍魔「機制與數值詳見 4.4.」

## 三、圖文對應

- **示意圖放右欄**，跟左欄文字同一個小節；圖的 caption 用《》框起來
- **分鏡圖整張一張貼右欄，不切成一分鏡一張**（Tim 2026-10-08 再確認，不跟劍魔的一分鏡一張圖）：caption《<表演名>分鏡示意圖》；圖上每格的「圖N」標籤對回左欄，左欄在該分鏡句尾寫 `〔圖3–4〕`
- 單張示意圖的小節（待機、受擊等）caption 用小節名：《待機動畫示意》《被捕獲動態示意》
- 舊（幻狐）的毛病是左欄跟圖各用一套編號（「圖A～F」配「圖1～8」），對錯格很常見；`〔圖N〕` 一律用圖上印的格號
- 參考圖（不是本 Boss 的畫面）caption 寫明「參考」：劍魔《受擊紅光參考》

## 四、劍魔範例摘錄（去識別化）

**待機動態(move)**
```
1. 基本動作：全程3秒
    1. 劍魔雙手拄劍立於舞台定點，身體隨呼吸節奏緩慢起伏
    2. 斷鏈與懸浮斷劍碎片持續緩慢環繞
    3. 頭盔窄縫的魔光隨節奏一明一暗
2. 全程循環不停，直到劍魔死亡；三階段各一套，不互相沿用
3. 階段差異：（表格，見第二節第 5 條）
```

**攻擊動態(move)**
```
1. 基本動作：
    1. 拔劍到一半，1秒
    2. 向下插入原位，1秒
    3. 左右幻化出劍刃碎片向前揮砍，劍鋒帶出一道魔氣劍痕，1.5秒
    4. 劍刃碎片消失，0.5秒
2. 定期觸發，插入待機循環之間
3. 表演順序沿用《〈既有 Boss〉》：待機 ×2 → 攻擊 ×1 → 重複
```

**必殺技（多步表演）**
```
1. 觸發時機：〈條件〉時觸發 1 次，全階共用同一套，不做階段差異
2. 分鏡四步：
    1. 預兆：畫面壓暗，魔氣自甲片縫隙逆流倒吸，1秒
    2. 匯聚：中間產生紫氣漩渦，由畫面外淡入小魚往漩渦中心飛入，3秒
    3. 吞噬：核心閃爆，小魚表演被捕獲動態後沒入體內消失；畫面震動，1.5秒
    4. 回血：魔氣漩渦灌回鎧甲，裂痕短暫發亮後收束；劍魔重新挺立、將劍往上拔出一小段，並用力向下插回原位，2秒
3. 血條需與第 4 步同步回升一整格
4. 圖層：Boss本體<魔氣漩渦<小魚們
5. 表演期間移除碰撞區，全程禁用冰凍卡；倒數不暫停
6. 造型更換需於分鏡1預兆時執行
7. 機制與數值詳見 4.x
```

**被捕獲動態(caught)**
```
a. 地板生成封印陣＋粒子光圈，1秒
b. 劍魔化為大量紫色魔氣被抽入法陣中後消散，2秒
c. 大量金幣由獎金欄噴向畫面四周，1秒
d. 表演期間移除碰撞區並禁止發炮，不會被子彈打到
```

## 五、舊寫法 vs 新寫法

| 項目 | 舊寫法（幻狐／賽特） | 新寫法（劍魔） |
|---|---|---|
| 待機 | 「尾巴自然擺動」「腳部動態自然擺動」 | 「全程3秒」＋逐部位動作＋「循環直到死亡」 |
| 秒數 | 「預計1秒」，有的步驟漏寫 | 每步句尾「，N秒」 |
| 階段差異 | 不寫 | 每個動態都寫「各一套／共用」，各一套時用表格落到部位 |
| 受擊 | 沒有這一節 | 層數、外觀、觸發頻率、技術層 |
| 攻擊插入 | 沒有 | 「待機 ×2 → 攻擊 ×1 → 重複」 |
| 用詞 | 「有一種神怒的感覺」「呈現蓄積的氛圍」 | 「魔氣自甲片縫隙逆流倒吸」 |
| 同步 | 不寫，或分散在別章 | 「血條與第 4 步同步」「造型更換於分鏡1執行」 |
| 圖層 | 不寫 | 「Boss本體<魔氣漩渦<小魚們」 |
| 表演期間規則 | 分散或沒寫 | 碰撞、發炮、道具卡、倒數寫在同一節 |
| 圖文對應 | 左欄「(圖C)」對右欄另一套編號 | 分鏡圖整張貼右欄，左欄句尾 `〔圖N〕` 對圖上格號 |

## 六、交付前自查

- [ ] 每一步句尾都有秒數（結束狀態除外）
- [ ] 沒有「自然」「感覺」「氛圍」這類詞；每個動作都點名部位或物件
- [ ] 待機寫了週期與循環終點；攻擊寫了插入規則
- [ ] 每個動態都寫了階段差異（各一套／共用）
- [ ] 有受擊回饋小節
- [ ] 有疊在 Boss 上的特效就寫圖層；有 UI 或造型變化就寫同步點
- [ ] 彩金表演、必殺技、被捕獲寫了碰撞／發炮／倒數
- [ ] 分鏡圖整張一張貼右欄；每個分鏡句尾有 `〔圖N〕`，且對得上圖上格號
- [ ] 數值與機制只寫「詳見 4.x」，不在動態節重寫一份
