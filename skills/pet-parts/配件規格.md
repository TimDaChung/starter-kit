# 寵物配件規格

> 規格與驗收的硬規範。`SKILL.md` 管流程，這份管「什麼叫做對」。
> 來源：道具之書三份史詩寵物企劃（霍克、章魚燒、摩卡）的美術需求表，以及 2026-09-30 神弓手霍克的首次實測。

---

## 一、做哪些、不做哪些

| 批次 | 部件 | 企劃位置 | 交付 |
|---|---|---|---|
| **1 動畫分鏡** | 一般／上陣／虛弱，**每個動畫一張、一階二階各一套**（每隻共 6 張） | 2.2.B（零星動態）、2.2.D（三星動態） | 灰底，每張 3–4 格＋程式標籤 |
| **2 技能 ICON** | 技能 1、2（技能 3 是公版禮包圖示，不做） | 2.3 技能表的「技能ICON」列 | 每個 ICON 一張正方形 PNG＋尺寸預覽 |
| **3 專屬背景** | 培育頁與上陣／尋寶格共用 | 2.4 UI 設計的「背景」 | 16:9 滿版 |
| 4 滿星貼圖（有才做） | 例：摩卡「朕最可愛！」 | 2.1.B、2.5 新增道具 | 二階定稿＋程式加字 |
| **5 道具 ICON（後製）** | 本體縮圖＋碎片版，一階／二階各一 | 不用盤企劃，定稿即做 | 512 正方形 PNG＋256／128／64 預覽；碎片版同圖左上疊角標；**不生圖** |

**不做**：解鎖 Dialog、名稱欄、儲值觸發畫面（公版 UI 換字）。寵物 ICON 與碎片 ICON **要出但不生圖**——走第五節的後製（Tim 定案 2026-09-30）。

---

## 二、動畫分鏡

- **每個動畫一張**：一般、上陣、虛弱分開畫，一階、二階各一套；**拿該階定稿當參考圖**
- **每張 3–4 格**，照企劃動態原文拆成關鍵姿勢，由左至右（3 格一列；4 格 2×2）
  - 循環動作（「A → B → A」）每個姿勢各一格，回到 A 的那步不重畫
  - 企劃寫的是靜態狀態、沒有順序（例：虛弱「盤腿坐著，頭、眼皮、雙翼下垂」）時，拆法是解讀——**列出拆法給使用者確認**
- **動作照企劃逐字寫，不增不減**：企劃沒寫的道具、表情、擺放一律不加（前科：虛弱自行加了「長弓放在地上」）
- 提示詞**逐項點名要保留的造型元素**，只寫「跟參考圖一樣」會被打折
- 格子標籤由 `scripts/label_frames.py` 加（「圖N＋這格在做什麼」），不寫秒數、不交給模型寫字
- **格子比例不強制 16:9**：引擎最寬約 3:1，一列 3 格時每格接近正方形——給動作師看姿勢反而更清楚
- **不轉身背對畫面**：背面看不到錨點
- 模型偶爾只畫一大張、沒分格：`label_frames.py` 會擋下來，重抽

## 三、技能 ICON

> 技能 ICON 是**技能圖示**，照生圖流程出（本節原樣）；道具 ICON 是**本體縮圖**，走後製，見第五節。兩者不要混。

- 同一隻寵物的 ICON **畫在同一張**（風格一致），`scripts/icon_check.py` 切成正方形
- 每個 ICON **自帶深色圓角方形底板**，主體大、剪影簡單
- **配色取自寵物**（寵物定稿當參考，但提示詞寫「不要把寵物畫進 ICON」）
- **64px 驗收**：看 `ICON_尺寸預覽.png` 的 64px 欄，一眼認不出主體就重抽。周圍特效光弧太多是最常見的失敗（縮小後糊成一團）
- ICON 內容可以取寵物的**錨點部位**（霍克的鷹眼有青綠虹膜＋黑色淚痕紋），辨識度會更好

## 四、專屬背景

- 16:9 滿版，**中央留乾淨區域給寵物本體**、主要景物放周圍與遠方
- **下方約 1/4 保持簡潔**（UI 疊在那裡）；企劃常會提醒「檯面避免細節太多」（章魚燒）
- 無角色、無動物、無文字
- 模型比例不準時用 `boss-design/scripts/fit_canvas.py --cover` 裁成 1920×1080

---

## 五、道具 ICON（後製，不生圖）

- 道具 ICON 就是**本體縮圖**，一律從兩階定稿後製，不用 image-studio 生（Tim 定案 2026-09-30；炮台翅膀、武具線同規）
- `scripts/item_icon.py`：從並排定稿取半（`--half left` 一階、`--half right` 二階）→ 裁主體、去灰底 → 疊深色圓角底板 → 出 512 主圖＋256／128／64 預覽
- **碎片版**＝同圖左上疊碎片角標（`--badge <路徑>`）。**碎片角標素材不進 repo**（線上 UI 素材裁切、kit 是公開 repo）：向主任拿，放本機 `skills/pet-parts/_工作暫存/fragment_badge.png`（已 gitignore），腳本用 `--badge <路徑>` 指路；沒有角標就只出主圖不出碎片版
- **64px 驗收**：看得出是這隻寵物（剪影＋主色）；認不出多半是主體太小或錨點太細——調 `--margin` 或用 `--region` 手動框，不回頭改定稿

---

## 六、共通

- **等 `pet-evolution` 的兩階定稿**才做：所有配件都衍生自定稿
- 畫風：姿勢示意跟本體一樣走「低面數 3D 寵物模型成品渲染、塊面大、手繪風貼圖」（與 pet-evolution 模板同步）；技能 ICON 與背景走 2D 手遊美術；道具 ICON 不生圖、直接裁定稿
- 特效光不可畫成螢光綠或黃綠
- **不修改既有企劃**；企劃文字與企劃圖不一致時列出來問使用者

---

## 七、驗收清單

**動畫分鏡**
- [ ] 一般／上陣／虛弱各一張，一階二階都有
- [ ] 每張 3–4 格，各格是同一隻、位置大小一致
- [ ] 循環動作的每個姿勢都有；沒有企劃沒寫的道具或動作
- [ ] 造型元素全部還在（對照提示詞點名的清單）
- [ ] 沒有背對畫面

**技能 ICON**
- [ ] 技能 1、2 都有（技能 3 公版不做）
- [ ] 64px 仍一眼看懂
- [ ] 配色呼應寵物，ICON 裡沒有畫寵物本體

**道具 ICON（後製）**
- [ ] 一階、二階各一張；有角標才有碎片版，角標在左上
- [ ] 64px 看得出是這隻寵物
- [ ] 灰底去乾淨、主體沒被裁到、底板圓角完整

**專屬背景**
- [ ] 1920×1080 滿版
- [ ] 中央留空、下方 1/4 簡潔
- [ ] 企劃的場景元素都有
