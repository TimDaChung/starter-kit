# 產圖提示詞模板

> 改提示詞只改這個檔。三份模板都來自 2026-09-30 神弓手霍克的成功提示詞。

---

## 一、動畫分鏡（每個動畫一張）

```
你是一位遊戲美術設計師。請繪製遊戲寵物「【寵物名】」的一段動畫分鏡圖，給 3D 動作師參考。

參考圖是這隻寵物的外觀定稿。每一格裡的造型、配色、服裝、比例都和參考圖完全相同，只改姿勢與表情：保留【逐項點名造型元素】。

版面要求：
a. 一張圖分成 【N】 格，排成 【1 列 × 3 欄／2 列 × 2 欄】，格與格之間留出明顯間隔。
b. 背景是單一純色的中性灰，各格都一樣。不要畫場景、地面或任何背景細節。
c. 各格共用同一隻寵物，位置與大小完全相同：站在畫面正中央，身高約佔畫面高度的七成。只有姿勢在變。
d. 畫面上不要有任何文字、數字或 UI。
e. 畫風：手遊 3D 寵物模型的成品渲染，立體、體積感強，柔和棚燈，卡通化的角色造型。
f. 不轉身背對畫面，每一格都是正面或斜側面。

各格內容（由左至右【、由上至下】）：
動畫：【一般動態／上陣動態／虛弱動態】（【企劃原文的一句概述】）。
- 第 1 格：【企劃原文拆出的姿勢】
- 第 2 格：【…】
- 第 3 格：【…】
```

交付前：`python scripts/label_frames.py <圖> <輸出> --cols 3 --rows 1 --captions "…|…|…" --title 一般動態`

## 二、技能 ICON

```
遊戲寵物的「技能 ICON」設計圖：【N】 個技能圖示，左右並排。

畫面：16:9 橫式，純灰色背景（無文字）。【N】 個 ICON 都是正方形構圖、大小相同、平均分佈置中，每個 ICON 自帶深色圓角方形底板。
畫風：高營收手遊的技能圖示，精緻厚塗，高飽和，主體大而清楚、剪影簡單——縮小到 64×64 像素時仍要一眼看懂。配色與參考圖的寵物一致（參考圖只用來決定配色與質感，不要把寵物畫進 ICON）。

1. 技能「【技能1名】」：【企劃技能ICON描述，補上顏色與寵物錨點】。
2. 技能「【技能2名】」：【同上】。
特效光不可畫成螢光綠或黃綠色。
```

畫風：高營收手遊的 2D 場景美術，精緻厚塗，柔和、明亮。
無文字、無 UI、無角色、無動物。

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 分鏡逐項點名造型元素 | 「跟參考圖一樣」會被打折，點名才保得住 |
| 每個動畫一張、動作照企劃原文、循環拆成多格 | 自己挑瞬間或補道具都是改企劃；循環的每個姿勢動作師都要看 |
| 「不轉身背對畫面」 | 背面看不到錨點，示意圖就失去用途 |
| ICON「縮小到 64×64 仍要一眼看懂」 | 不寫的話模型會堆滿特效光弧 |
| ICON「不要把寵物畫進 ICON」 | 參考圖是角色時，模型預設會把角色畫進去 |
| 背景「中央留給寵物」「下方 1/4 簡潔」 | 寵物與 UI 都疊在背景上 |
