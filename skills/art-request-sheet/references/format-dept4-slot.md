# 美術需求表格式規格（四部機台）

來源：四部 PM 手做的 4 份機台美術需求表（3 份新機台、1 份改版），2026-10-06 匯出 xlsx 逐格讀過；原檔與摘錄放在網芳 `X:\grp.product.pm1\2. 產品改造\一四部企劃範本\kit-assets\art-request-sheet\`（X 讀不到換 Y:）的 `dept4-slot-samples\` 與 `實際範例-dept4-slot.md`。

`build_sheet.py` 照 `scripts/layouts/dept4-slot.json` 產表；改格式就改那份 json，再回來更新這份。4 份範例彼此不一致的地方，layout 取**較新的兩份**（同一位 PM 的新機台＋改版）為預設，下面每條都標出來源；標「**待主任拍板**」的是範例沒有統一規則、目前先照新版走的項目。

## 檔名

範例實況：3 份只寫機台名（或「類型_機台名」），只有改版那份是 `v<版號>_<名稱>`。**待主任拍板**：要不要比照一部統一成 `v<版號>_<機台名>_<企劃名>`。拍板前照 SKILL.md 第 5 步：先問使用者要哪種，不自己決定。

## 分頁

| 分頁 | 必要 | layout key | 範例實況 |
|---|---|---|---|
| 靜態 | 必有 | `static` | 4/4 有；名稱有「靜態」「美術靜態」「美術靜態表」三種 |
| 動態 | 必有 | `dynamic` | 4/4 有；名稱同上三種 |
| 動態命名表 | 選用 | `naming` | 1/4 有（spine 檔名、animation name、秒數、event） |
| 說明頁 | 選用 | `help` | 2/4 有 |

- 分頁名預設用最短的「靜態／動態／說明頁」（新版兩份的寫法）。**待主任拍板**：分頁名統一用哪一種。
- 有一份表另有「競品分析」分頁（競品截圖對照），只出現一次，不列入 layout。
- 第一個分頁沿用使用者給的空白表；其他分頁由 `add_sheets.json` 建（流程見 SKILL.md 第 3 步）。

## 靜態分頁

| 欄 | 表頭 | 誰填 | 內容 |
|---|---|---|---|
| A | 項目 | 企劃 | 畫面名稱（＝企劃第 2 章的一節）；同畫面多列時**垂直合併** |
| B | 子項目 | 企劃 | 元件名，常見寫法「A.天列」「B.背景」或「i.天列」；獎圖一個 symbol 一列 |
| C | 重要度 | 企劃 | 1–5 或 `-`（純文字，沒有下拉） |
| D | 動態 | 企劃 | Y／N |
| E | 企劃示意圖 | 企劃 | 企劃裡的示意圖；同畫面共用一張時**垂直合併**，圖錨在合併區第一列 |
| F | 描述 | 企劃 | 「風格／樣式／規格」分段，見 writing-rules-dept4-slot.md；留空即與上一列合併 |
| G | 美術字需求 | 企劃 | 畫面上要做成美術字的文案；沒有就留空 |
| H | 參考圖1 | 企劃 | 局部示意、競品、既有素材 |
| I | 參考圖2 | 企劃 | 同上 |

範例差異：

- **重要度**欄只有新版兩份有（**待主任拍板**：要不要保留；舊版兩份沒有這欄）
- **參考圖3**只有一份有；layout 預設兩欄（**待主任拍板**）
- 有一份 A1 表頭是空白、A 欄沒寫「項目」；layout 一律寫「項目」
- 「動態」欄有一份叫「美術是否需要製作」（在動態分頁）；靜態分頁 4 份都叫「動態」

## 動態分頁

| 欄 | 表頭 | 內容 |
|---|---|---|
| A | 項目 | 動畫的主體（角色、物件、Dialog）；垂直合併 |
| B | 時機 | 何時播（待機、投球、被擊中…）；改版那份寫成完整觸發條件 |
| C | 企劃示意圖 | 企劃圖；同主體共用一張時垂直合併 |
| D | 描述 | 「動態需求：」＋編號步驟，或「時機：／動畫：」兩段 |
| E | 動態參考 | 參考影片轉的 GIF、競品片段、既有素材路徑 |
| F | 動態參考2 | 同上 |

範例差異：舊版兩份第 2 欄是「子項目」或「美術是否需要製作（Y）」，參考欄叫「參考圖1／2」或「動態參考1／參考2」；layout 用新版「項目／時機／企劃示意圖／描述／動態參考／動態參考2」（**待主任拍板**）。

## 動態命名表（選用）

| 欄 | 表頭 | 內容 |
|---|---|---|
| A | No | 編號；同一物件多個 animation 時垂直合併 |
| B | 名稱 | 物件名（範例此欄表頭是空白，layout 補「名稱」） |
| C | 動態檔案名稱 | spine 檔名 |
| D | 動態檔案裡的ANIMATION NAME | 表頭底色 `#B7B7B7` |
| E | 說明 | 觸發時機 |
| F | 秒數 | 例：`1s`、`2~3s` |
| G | 備註及重要流程描述 | 動作細節、spine event 名 |
| H | 示意圖 | 指回靜態／動態分頁的連結或圖 |
| I | 競品參考 | |
| J | 補充 | 命名規則備註 |

- 分類列（例：「大廳icon」「獎圖」「盤面動畫」）整列底色 `#70AD47`、白色粗體字；spec 用 `{"section": "分類名"}`
- 全表字型 Microsoft JhengHei 15pt、表頭粗體底色 `#E2EFD9`、細框線（照範例）
- **企劃不會寫 spine 命名**：企劃沒寫就只建空表頭（`"rows": []`），列進缺漏清單，不要自己編檔名或 animation name

| 欄 | 表頭 | 內容 |
|---|---|---|
| A | （空白） | 有一份寫「說明頁1、2…」 |
| B | 標題語言ID | 有一份表頭是「說明」 |
| C | 英文標題 | |
| D | 繁中標題 | 企劃第 4 章每一頁的標題 |
| E | 翻譯 | |
| F | 中文 | 企劃第 4 章該頁的內文 |
| G | 圖片說明 | 企劃第 4 章該頁的示意圖 |

表頭底色 `#8DB3E2`、白色粗體 14pt；沒有第 2 列，內容從第 2 列開始；列高約 340px（放得下示意圖）。

## 樣式（靜態、動態分頁）

| 部位 | 規格 | 來源 |
|---|---|---|
| 第 1 列表頭 | 底色 `#4A86E8`、白字、Microsoft JhengHei、水平置中、不粗體 | 4/4 一致 |
| 第 2 列 | 底色 `#C9DAF8`，不合併；靜態分頁 A2 寫「ETA︰」（日期留給美術或 PM 填），動態分頁空白 | 底色 4/4 一致；「ETA︰」新版兩份有、舊版兩份是空白合併 A2:B2（**待主任拍板**） |
| 內文字型 | 不另設（Sheets 預設 Arial 10pt） | 新版兩份；舊版一份全表 Microsoft JhengHei 12pt（**待主任拍板**） |
| 對齊 | 項目、子項目、重要度、動態、時機置中；描述靠左；全表自動換行、垂直置中 | 4/4 一致 |
| 畫面分隔 | 每個「項目」群組最後一列下緣**雙線**，其他不畫框線 | 2 份雙線、1 份另有粗線、1 份無框線 |
| 凍結 | 凍結前 2 列 | 3/4 有凍結但列數不一（1、2、2 列，其中兩份另凍結 1–2 欄）（**待主任拍板**） |
| 動態欄 | 資料驗證下拉 Y／N（嚴格、顯示下拉） | **範例 4 份都是手打純文字、沒有資料驗證**（xlsx 原始檔與網頁畫面都確認過）；kit 一律加下拉，避免打錯值（**主任 2026-10-07 定案**） |
| 欄寬（px） | 靜態 A100 B120 C50 D40 E400 F450 G150 H300 I300；動態 A110 B130 C380 D240 E200 F200 | 範例差很多（企劃示意圖欄 330–745、描述欄 395–605）；取新版兩份的中間值 |
| 列高 | 依描述行數估，最少 60px；有圖的列至少是縮完的圖高＋10px（合併列共用一張圖時分攤到合併範圍），不用貼圖後手動拉高 | 範例依圖拉高，30–520px 不等 |
| 紅字 | 只標片段，照企劃原文的紅字 | 範例幾乎沒用（4 份合計 2 處片段、3 格整格）；照一部規則保留 |
| 灰底 | 不用 | 舊版兩份把「不需要填」的格子塗灰（`#CCCCCC`／`#999999`），新版兩份沒有 |

## 參考圖

- 浮在儲存格上方（不是「插入儲存格內」），錨點在該格左上角；範例 4 份都是這種（xlsx 裡沒有儲存格內圖片）
- 企劃示意圖放「企劃示意圖」欄（同畫面合併時放合併區第一列），其他參考放參考圖欄
- 影片轉 GIF 放動態分頁的「動態參考」欄；範例也有直接寫網芳影片路徑或「點我看」超連結的做法
- 縮圖上限＝layout 各圖片欄的 `thumb`（欄寬 −20 × 300）：靜態企劃示意圖 380×300、靜態參考圖 280×300、動態企劃示意圖 360×300、動態參考 180×300、命名表示意圖 380×300、競品參考 100×300、說明頁 430×300
