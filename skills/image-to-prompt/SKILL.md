# image-to-prompt（圖 → 中性化可換角色 prompt）

## 目的

使用者給一張圖，產出一段 prompt，**還原這張圖的「風格＋構圖＋排版」**，但**抽掉跟特定角色綁死的具體物件**，讓同一段 prompt 換掉角色名就能套用到別的角色。

**核心原則：可逆向的是「風格語言」，不是「這個角色的道具」。** 角色相關的元素要寫成「角色身上會有的東西」這種通用敘事描述，由 AI 依角色名自己填。

## 這不是什麼

- 不是讀出原作者真正用的 prompt（同一張圖有無數種 prompt）。產出的是「能重現這個視覺效果」的版本，要對使用者講清楚。
- 原圖若是真人手繪／實拍 → 沒有 prompt，只能描述特徵，照樣中性化。

## 流程

1. **Read 圖**（使用者給路徑就直接 Read；貼圖則直接看）。
2. 依下方「拆解層次」逐層觀察，抓出風格 DNA。
3. **中性化**：把角色專屬元素改寫成通用敘事語言（見下表）。
4. 套「整合句式」輸出一段連貫的 prompt（使用者偏好一整段流暢敘述，不是條列 tag）。
5. 角色名、標題文字一律留 placeholder。
6. **結尾問使用者要中文還是英文版**（GPT/DALL-E 吃英文較準，且版權角色中文名容易被擋；中文 prompt 適合理解力強的模型）。除非使用者已指定。

## 中性化規則（核心）

跟角色強綁定的具體物件 → 改成「會依角色變化的通用槽位」：

| 原圖具體元素（綁死角色） | 中性化後（可換角色） |
|---|---|
| 獅子虛影、特定召喚獸 | 「與角色有強烈關聯的代表性虛影意象（精神象徵／命運生物／宿敵／回憶場景）」 |
| 槍刃、特定武器 | 「角色的標誌性武器或關鍵物件，作為對角貫穿畫面的主線索」 |
| 立體機動裝置、某招牌道具 | 「角色身世與身分的象徵物件」 |
| 特定服裝（黑皮衣毛領） | 「角色設定服裝」＋讓 AI 依角色還原 |
| 寫死的標題字（LIONHEART） | 「商業海報級大標題與副標排版，內容由 AI 依角色名自由設計」 |

**保留（這些就是風格 DNA，要寫死）：** 畫風／上色法、構圖鏡頭、光影、配色調性、留白、特效質感（碎裂／水墨暈染／雙重曝光）、版面層級、長寬比。

## 拆解層次

- **角色主體**：半身／全身、鏡頭角度（仰角英雄／俯角）、姿勢、視線方向、情緒 →（角色名 placeholder）
- **畫風**：半寫實厚塗／米哈遊 key art／美式厚塗／水墨／像素…、線條與上色（幾何切面感／cel shading）
- **構圖**：視覺層級（上大下小）、主體佔比、留白、左右輔景、貫穿線索
- **光影**：電影級柔光／邊緣光／逆光、對比、景深
- **配色**：單色調 or 主色點綴、高對比低飽和、冷暖
- **敘事元素**：背景特效與意象 → **中性化**
- **排版**：標題層級、副標、商業海報語言 → placeholder
- **技術**：長寬比（9:16 直板等）

## 範例（這個 skill 的標準示範）

一張 FF8 Squall 的 LIONHEART 風格海報，逆向 →：

> 一張「【角色名】」的人物宣傳海報，採用直式主視覺構圖。畫面以仰角英雄鏡頭呈現角色半身為視覺核心，人物視覺完整還原角色設定，視線望向畫面外上方，神情帶有角色標誌性的情緒張力。角色周圍以象徵其身世與內心的意象進行雙重曝光與拼貼式敘事——將與該角色有強烈關聯的代表性虛影意象（如其精神象徵、命運生物、宿敵或回憶場景）自背景的碎裂、流動、暈染中浮現；並讓角色最具辨識度的標誌性武器或關鍵物件作為一條對角貫穿畫面的主線索，連結人物、背景意象與整體構圖。背景採高級單色調，搭配大面積留白與邊緣的破碎、虛化、暈染處理，營造虛實呼吸感。柔和電影級光影、強烈邊緣光、高對比低飽和配色，僅以角色主色作少量點綴。幾何切面感厚塗上色，細緻皮膚與髮絲、金屬與材質高光。下方配置商業海報級大標題字體設計與副標排版，標題內容由 AI 依角色名自由設計。整體風格統一、高級而克制，強調層次感、敘事性與主視覺衝擊力。尺寸：9:16 直板。

注意：原圖的「獅子」「槍刃」都沒寫死，換成「代表性虛影意象」「標誌性武器」——換成別的角色（如進擊的巨人艾連）就會自動變成巨人輪廓與立體機動裝置。

## 常見錯誤

- ❌ 寫死角色專屬道具（獅子、槍刃）→ 換角色就壞。**改通用槽位。**
- ❌ 輸出一堆逗號分隔 tag → 使用者要一整段連貫敘述。
- ❌ 把標題文字內容寫死 → 留給 AI 依角色設計。
- ❌ 過度具體到把「這個角色」描述進去 → 只描述「角色設定服裝／情緒」，靠角色名 placeholder 還原。
- ❌ 沒問中文還是英文版 → 結尾要問（除非已指定）。

## 銜接：產出 prompt 後接哪支生圖 skill

拆解產出的 prompt、換上角色名後，依目標直接接續對應 skill 生圖：

- 角色立繪／半身像／角色卡 → `imagen-portrait`
- UI 素材（icon／卡框／頭像框／banner） → `imagen-ui`
- 2D 地圖／場景／戰鬥背景 → `generate2dmap`
- 角色 sprite／動畫表 → `generate2dsprite`（cel-shaded chibi／Q 版風改用 `generate2dsprite-chibi`）
- 其他通用生圖需求 → `imagen`
