# 共用規範對照（一＋四部）

`plan-dept14-writer`（寫／改企劃）、`plan-doc-qa`（審查）、`art-request-sheet`（拆美術需求）共用：**企劃內容碰到下表的觸發詞，就現讀那一頁，照頁上的規範寫**。

- 範本（`notion-templates.md`）管**結構**；本表管**跨企劃共用的內容規則**——倒數格式、按鈕樣式、Dialog 順序、Boss 計數、稀有度、Buff 號碼……這些不寫在範本裡，漏看就會跟既有系統不一致。
- **Notion 頁是權威、每次現讀**（讀法同範本：`art-request-sheet/scripts/fetch_plan.py <page id> <out_dir>`）。本表只放主題、觸發詞與 page id，**不抄規範內文**——數值與規則一律以頁面當下內容為準。
- 頁上的規則跟企劃寫法衝突 → 照頁面寫，交付時一句話說明；企劃**刻意**要違反（特規）→ 在企劃註明「特規，不照〈頁名〉」，並問 PM 要不要回寫共用頁。
- 盤點日：2026-10-12（四個庫逐頁實讀）。

## 五、怎麼用（寫企劃時）

1. **新建**：§一 判庫 → 草擬畫面清單與規則章大綱時，掃一次本表觸發欄；命中的頁現讀，規則直接照寫（不重抄整頁，寫「依〈頁名〉」並把會影響 client 實作的那條寫進條文）。
2. **調整**：只查這次改動碰到的觸發詞。
3. **交付訊息**附一行「已對照共用規範：〈頁名〉…」；新增 dialog／儲值觸發／Buff／機台共用功能這類**登記型**項目，提醒 PM 上線後回填對應總表。
4. 本表沒列、但 PM 說「照某某規範」→ 照 PM 給的頁，並建議補進本表。
