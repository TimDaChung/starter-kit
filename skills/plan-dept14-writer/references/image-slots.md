# 企劃貼圖：圖放哪、怎麼放

`plan-dept14-writer` 第八節「貼圖模式」的權威參考；各生圖 skill 的「貼回企劃」段也指向這份。
來源：2026-10-02 實讀一部／四部企劃 63 頁（一部 24、四部 39）＋兩份 Notion 編寫手冊。**頁面既有寫法與本表不同時，跟隨頁面**，並回報一句。

---

## 一、兩部共通鐵律

1. **左文右圖**：兩部手冊都明寫「兩欄，文字於左邊，圖於右邊」。圖放在該節 `column_list` 的**最後一欄**，同節多張由上往下疊。四部 Boss 頁 121 張圖全部在右欄（`3d5e22985ac98097a0a7e970870bd5ec`、`3aee22985ac980158e84eed47a528876`）
2. **圖片一律 file 上傳**（`paste_images.py` 走 File Upload API），不用 external 連網芳；網芳路徑只以文字寫在「網芳上傳」表格
3. **含圖表格**：Notion 表格放不了圖。純參考 → 整張做成圖貼上；帶工程設定 → 用分欄做假表格（至多 5 欄、列間分隔線）；四部另可「圖放表格上方、多張小圖拼成一張、每張下方標名稱或編號」
4. **圖若是後文的講解對象**：圖上用框線＋標號分區，標號對應左欄有序項目，從左到右、上到下（兩部手冊皆同）。AI 示意圖不在圖上加標號，標號由 PM 決定要不要
5. **不准動的圖**：PM 放的實圖、美術產物、參考圖一律不換不刪。點名：炮台／翅膀／套裝頁 2.1.B 下的「0/2/4 星遊戲內對位條」、廣宣頁《wow現有廣宣》、大活動頁的美術稿。只換卡位、只在空位新增

## 四、synced_block（四部魚樂園必看）

魚樂園物件頁的內容包在頂層 **synced_block 原件**裡，版本頁（例 v8.7 `3bae…b892`）的 📌toggle 只是同步參照。**圖貼進物件頁的原件，版本頁自動帶出**；貼在參照或頁面根層會出錯或只出現一邊。`list` 會標 `[SYNCED ORIGINAL]`／`[SYNCED REF -> …]`。例外：摩卡鬥鼠、神杖光翼、劍魔沒有 synced 包裝，物件頁與版本頁各存一份，兩邊都要貼（先問 PM）。

## 七、一部大活動：從美術網芳自動找圖（`scripts/art_share_slots.py`）

適用：**神娃大活動、人物大活動、神裝禮包**三種頁（標題開頭 YYMM）。其他頁照第五節，PM 給檔才貼。
驗證：2608～2611 九頁 110 張實貼圖逐張比對，106 張命中規則（其餘 4 張是吃碰特效截圖），2026-10-08。

### 流程
1. `python <skill-dir>/scripts/art_share_slots.py list <網址> [--json out.json]`：只讀。判頁型與 YYMM → 找月份資料夾 → 每格推檔 → 跟頁上已貼的圖比對（MD5，不同再比像素；檔名只當輔助）
2. 把清單（人看的表）給 PM 核准。狀態：**空格待貼**／**已貼且相同**／**已貼但網芳不同**（附 diff 分數，美術貼後又改稿很常見）／**網芳缺檔**／**需確認(多個候選)**／**需人工**
3. `paste <網址> --confirm`：只貼「空格待貼」；「網芳不同」要 PM 點頭後加 `--replace`（可配 `--only <slot>` 只換指定格），原地換圖、block id 不變。不加 `--confirm` 只印計畫（dry run）
4. 腳本貼完自己回讀：重跑比對，被動到的格子必須變成「已貼且相同」才算過
5. 資料夾推不出來（找不到、同前綴多個、名稱月份與前綴不符）→ 腳本**停下列候選**，不猜；PM 選定後用 `--avatar-dir`／`--headshot-dir`／`--char-dir` 指定重跑
