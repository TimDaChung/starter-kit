## 一、武具 ICON

```
遊戲武具的「ICON」設計圖：一個正方形圖示，畫面中央、大而清楚。

畫面：純灰色背景（無文字），ICON 自帶深色圓角方形底板，底板色調是深棕與深藍的暗色調。
內容：參考圖這件武具的縮圖——整件武具斜放（左下到右上），佔滿底板約八成，招牌部位【招牌部位】朝向畫面上方、最清楚。造型、配色、材質與參考圖完全相同，只簡化最細的花紋。
畫風：高營收手遊的道具圖示，精緻厚塗，高飽和，主體大、剪影簡單——縮小到 64×64 像素時仍要一眼看出是【武器類型】。
不要畫人、手、角色；不要文字、數字、UI；不要畫特效光弧與粒子；底板以外不畫任何東西。
```

交付前：`python ~/.claude/skills/pet-parts/scripts/icon_check.py <圖> <輸出資料夾> --names <武具名>`

## 二、碎片 ICON

**不生圖。** 用批 1 的 ICON 定稿與 `assets/` 的通用碎片角標，跑：

```sh
python ~/.claude/skills/weapon-parts/scripts/fragment_badge.py <ICON_武具名.png> <角標.png>
```

第一次沒有角標時，用 image-studio 算一顆通用角標（一次，存進 `assets/`，之後所有武具共用）：

```
遊戲道具的「碎片」角標：一個小圖示，畫面中央、單獨一個。
內容：一枚有裂痕的碎片，形狀像不規則的晶片或碎鐵片，邊緣有兩三道裂紋，帶金屬與寶石感的高光。
畫風：高營收手遊的 UI 小圖示，精緻厚塗，輪廓粗而清楚——縮到 24×24 像素仍認得出是「碎片」。
純色背景，方便去背。無文字、無其他物件、無底板。
```

角標用 `--remove-background` 去背存成透明 PNG（它是唯一要去背的產出）。

## 三、登場動畫分鏡（2×2 四格）

```
你是一位遊戲美術設計師。請繪製遊戲武具「【武具名】」的登場動畫分鏡圖，給 3D 動作師與特效師參考。

參考圖是這件武具的外觀定稿。每一格裡的造型、配色、材質、比例都和參考圖完全相同，只改位置、角度與特效：保留【逐項點名造型元素，例：藍白雙劍、劍格龍首、深藍絲繩柄、金色穗帶】。

版面要求：
a. 一張圖分成 4 格，排成 2 列 × 2 欄，格與格之間留出明顯間隔。
b. 背景是單一純色的中性灰，各格都一樣。不要畫場景、地面或任何背景細節。
c. 各格共用同一件武具，出現在畫面正中央，大小相同，武具高約佔格子高度的六成。只有姿態與特效在變。
d. 畫面上不要有任何文字、數字或 UI。
e. 畫風：手機捕魚遊戲的低面數 3D 道具模型成品渲染——塊面大而簡潔、面數少、手繪風貼圖、刃口與紋路帶自發光，柔和棚燈。不是寫實 3A 質感。
f. 不畫人、手、角色。

各格內容（由左至右、由上至下），登場動畫約 1–2 秒：
- 第 1 格（中間出現）：【武具在畫面正中央出現的狀態；有機關的武具寫初始收合態，例：只有神獸頭、盾面未展開】
- 第 2 格（招牌動作 A）：【企劃 §2.9 第 2 步原文，例：兩把劍稍微往後退、原地旋轉——藍劍逆時鐘、白劍順時鐘，畫出旋轉的殘影】
- 第 3 格（招牌動作 B）：【企劃 §2.9 第 3 步原文，例：兩把劍交叉到定位，與一般狀態相同的位置】
- 第 4 格（統一發光）：武具回到定位不動，背後散出【金光／配合武具主色的光芒】，光從武具後方向外擴散。
```

交付前：`python ~/.claude/skills/pet-parts/scripts/label_frames.py <圖> <輸出> --cols 2 --rows 2 --captions "中間出現|<動作A>|<動作B>|統一發光" --title 登場動畫`

## 四、3 星以上金色閃點版

同第三節的模板，**版面要求**與**各格內容**照抄，只加下面這段放在「各格內容」之前，並在第 2、3 格的描述後各補一句閃點路徑：

```
這是升到 3 星以上的升級版登場動畫：從第 1 格開始，武具周圍就飄著細小的金色閃點（星芒狀、大小不一、帶柔光），數量適中、不遮住武具。閃點的位置與飄動路徑跟著招牌部位走：【依武具寫，例：扇→沿扇面旋轉的軌跡拖出弧線；弩→跟著電光沿弩臂由內向外；盾→跟著鐵鍊由下而上；雙劍→繞著兩劍的旋轉軌跡】。第 4 格金光擴散時，閃點一起向外飄散。
```

參考圖可以改給**批 3 的分鏡定稿**（鎖住四格的姿勢，只加閃點），實測哪個穩再回寫這裡。

交付前：`label_frames.py … --title "登場動畫（3星金閃）"`

版面：一條橫幅置於畫面中央偏上，橫幅底是深棕與深藍的暗色調、邊緣有淡金色描邊。橫幅左側約三分之一放這件武具「【武具名】」（參考圖的定稿，縮小、微微傾斜、造型配色完全相同）；橫幅右側三分之二完全留空，不畫任何東西（之後會放文字）。橫幅以外是單一純色的中性灰背景。

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| ICON 寫「參考圖這件武具的縮圖」 | 武具 ICON 就是武具本身（企劃 §2.3.B「ICON：武具縮圖」），跟寵物技能 ICON「不要畫寵物」相反 |
| ICON 底板寫深棕深藍、不寫稀有度黃 | 稀有度底色與框由 UI 疊（§2.3.B），畫進 ICON 會疊兩層 |
| ICON「不畫特效光弧」 | 寵物線前科：光弧在 64px 糊成一團 |
| 碎片不生圖 | 企劃寫「以武具 icon 為基礎，在左上加碎片圖示」——是合成，不是新圖；程式做才能保證每把的角標一致 |
| 分鏡逐項點名造型元素 | 「跟參考圖一樣」會被打折，點名才保得住（寵物線實證） |
| 分鏡格序寫死、動作照 §2.9 原文 | PM 註記統一「中間出現 → 動作 → 統一發光」；自己補動作就是改企劃 |
| 第 4 格寫「回到定位不動」 | 不寫的話模型會再加一個新動作，發光格就不是收尾 |
| 金閃「數量適中、不遮住武具」「跟著招牌部位走」 | 企劃 §2.9 第 3 點：每把都用金閃，但位置與路徑依武具動態調整 |
| 追擊提示右側「完全留空」 | 文字後製；留空區域寫死才不會被模型塞裝飾 |
