# 武具配件規格

> 規格與驗收的硬規範。`SKILL.md` 管流程，這份管「什麼叫做對」。
> 初版（2026-09-30）來源：功能之書〈武具系統〉§2.3.B（武具欄 ICON 與碎片）、§2.7 道具列表（碎片美術需求）、§2.7〈武具追擊動畫〉、§2.9 登場動畫、§2.10 介面播登場動畫；ICON 與分鏡規格沿用 pet-parts 已實測的做法。**尚未用武具實測**。

## 一、做哪些、不做哪些

| 批次 | 部件 | 企劃位置 | 交付 |
|---|---|---|---|
| **1 武具 ICON** | 武具欄縮圖，也是碎片 ICON 的底 | §2.3.B「ICON：武具縮圖」 | 正方形 PNG＋尺寸預覽 |
| **2 碎片 ICON** | ICON 左上疊碎片角標 | §2.7「以武具 icon 為基礎，在左上加上碎片圖示；邏輯同炮台翅膀碎片」 | `ICON_<名>_fragment.png`，程式合成 |
| **3 登場動畫分鏡** | 一張 2×2 四格 | §2.9 各把的動畫流程；§2.10 介面切換也播 | 灰底 16:9＋程式標籤 |
| **4 金閃版分鏡** | 3 星以上升級版，同四格＋金色閃點 | §2.9 第 3 點；§2.10「3 星解鎖：登場動畫升級」 | 同上 |

## 二、武具 ICON

- **一把一張**，正方形構圖，畫在灰底上，`pet-parts/scripts/icon_check.py --names <武具名>` 切成正方形（預設 512px）並產 256／128／64px 預覽
- ICON 內容**就是武具本身**（縮圖），斜放佔底板約八成、招牌部位朝上；跟寵物技能 ICON「不畫寵物」相反
- **自帶深色圓角底板**（深棕深藍暗色調）；**不畫稀有度黃底與彩框**——那是 UI 依稀有度疊的（§2.3.B）
- **64px 驗收**：看 `ICON_尺寸預覽.png` 的 64px 欄，一眼認不出武器類型就重抽。特效光弧、粒子是最常見的失敗（寵物線前科）
- 未解鎖時 UI 會壓黑加鎖頭、未開放壓黑——ICON 本身要在壓黑後仍看得出輪廓，所以底板要夠深、武具要夠亮

## 三、碎片 ICON

- **不生圖**。碎片 ICON ＝ 武具 ICON ＋ 左上角碎片角標，由 `scripts/fragment_badge.py` 合成
- **角標**：所有武具共用 `assets/fragment_badge.png`——2026-09-30 從企劃〈武具系統〉§2.7 道具列表的示意圖（`img_12`，玄暝雙龍劍碎片那顆金色拼圖）裁下去背，**就是線上用的碎片圖示**，不用再生。角標 PNG 是線上素材的裁切，不外流、不進其他 repo
- **比例與位置**：角標邊長＝ICON 邊長的 **28%**（`--scale 0.28`；腳本預設 35% 會蓋到龍首，線上比例約三成），貼**左上角**（`--corner top-left`），內縮 ICON 邊長的 4%（`--margin 0.04`）。§2.3.B 寫「左上方依稀有度顯示碎片圖示」——稀有度差異目前只有傳說，角標不分色；未來多稀有度時換不同角標檔，比例位置不變
- 輸出命名：`<原檔名>_fragment.png`，與 ICON 同資料夾
- 驗收：角標不能蓋到招牌部位；64px 下角標仍看得出是「碎片」而不是污點（用 `icon_check.py` 再跑一次預覽）

## 四、登場動畫分鏡

- **一張 2×2 四格**，16:9 灰底，格序**固定**：

| 格 | 內容 | 來源 |
|---|---|---|
| 1 | 中間出現 | §2.9 PM 註記「武具從中間出現」；有機關的武具畫初始收合態（盾：只有神獸頭） |
| 2 | 招牌動作 A | §2.9 該把流程第 2 步原文 |
| 3 | 招牌動作 B | §2.9 該把流程第 3 步原文 |
| 4 | 統一發光 | §2.9「武具背後散出金光 or 配合武具顏色光芒」；武具回到定位不動 |

- **動作照企劃逐字寫，不增不減**：企劃沒寫的動作、特效、角度一律不加（寵物線前科：虛弱自行加了「長弓放在地上」）。從零發想的武具照 mini 企劃的登場動畫概念拆，拆法先給使用者確認
- **四格是同一件武具**，位置與大小一致（正中央、約格高六成），只有姿態與特效變；提示詞**逐項點名要保留的造型元素**
- **不畫人、手、角色**；不畫子彈與魚（登場動畫是攻擊畫面的一段，但分鏡只看武具）
- 標籤由 `pet-parts/scripts/label_frames.py --cols 2 --rows 2` 加（「圖N＋這格在做什麼」），不寫秒數、不交給模型寫字；只畫一大張沒分格會被腳本擋下，重抽
- 每格接近 16:9（整張 16:9 切 2×2），武具高約六成；橫向武具（弩、扇）以寬度為準不被切到

## 五、金閃版分鏡（3 星以上）

- **同四格、同格序、同姿勢**，差別只有金色閃點：從第 1 格就有，星芒狀、大小不一、帶柔光、數量適中、不遮武具
- **閃點位置與飄動路徑依招牌部位**（§2.9 第 3 點「每個武具都是用金色閃點，但依不同武具動態調整閃點的位置和飄動路徑」）：

| 武具 | 閃點路徑 |
|---|---|
| 玄暝雙龍劍 | 繞著兩劍旋轉的軌跡，交叉時匯到交點 |
| 離火飛鳳扇 | 沿扇面旋轉軌跡拖出弧線 |
| 麒麟神機弩 | 跟著電光沿弩臂由內向外 |
| 震威伏煞盾 | 跟著鐵鍊由下而上 |

- 第 4 格金光擴散時閃點一起向外飄散
- 參考圖可給批 3 的分鏡定稿鎖姿勢；哪個穩，實測後回寫第九節
- 驗收：閃點在 64px 縮圖不需要看得見（它是動畫特效），但**四格對照批 3 姿勢要一致**——姿勢跑掉就是重畫了分鏡，不是加閃點

## 六、追擊提示格（選做）

- **使用者要才做**。§2.7〈武具追擊動畫〉：射出第一發子彈後，跳提示「左方顯示技能來源武具，右方文字『追擊效果觸發』，出現約 1 秒後消失」；「文字與底色配色依美術調整」
- 一張 16:9 灰底：中央偏上一條橫幅（深棕深藍暗底、淡金描邊），左 1/3 放武具定稿縮圖，右 2/3 留空
- **文字後製**：`fit_canvas.py --whole` 補成 1920×1080 後，用 PIL 加字（不另寫腳本，字型候選照 `label_frames.py` 的 `FONT_CANDIDATES`）：

```python
from PIL import Image, ImageDraw, ImageFont
img = Image.open("追擊提示.png").convert("RGB")
font = ImageFont.truetype("C:/Windows/Fonts/msjhbd.ttc", 96)
ImageDraw.Draw(img).text((1080, 460), "追擊效果觸發", font=font, fill=(255, 220, 120), anchor="lm")
img.save("追擊提示_文字.png")
```

  座標依橫幅實際位置調；文字色先用暖金，配色本來就「依美術調整」，示意即可
- 驗收：橫幅右側沒被模型塞裝飾；武具縮圖造型配色與定稿一致

## 七、共通

- **等 `weapon-design` 的定稿**才做：所有配件都以定稿為參考圖
- 畫風：ICON 走 2D 手遊道具圖示；分鏡跟本體一樣走「手遊 3D 道具模型的成品渲染」；追擊提示走 UI 示意
- 特效光不可畫成螢光綠或黃綠；金閃是暖金
- **不修改既有企劃**；三把「暫放」武具沒有美術需求時，分鏡只能照 §2.9 動畫概念做，列為缺件回報
- **不做兩階**：武具升星不改外觀，五個產出各一套；金閃版是分鏡的第二套，不是第二階

## 八、驗收清單

**武具 ICON**
- [ ] 正方形、自帶深色底板、沒有稀有度黃底或彩框
- [ ] 64px 仍一眼看出武器類型
- [ ] 造型配色與定稿一致；沒有特效光弧

**碎片 ICON**
- [ ] 角標在左上、邊長約 35%、沒蓋到招牌部位
- [ ] 64px 下角標仍看得出是碎片
- [ ] 檔名 `ICON_<武具名>_fragment.png`

**登場動畫分鏡**
- [ ] 2×2 四格，格序＝中間出現／動作 A／動作 B／統一發光
- [ ] 動作 A、B 是企劃 §2.9 原文，沒有多加的動作或特效
- [ ] 四格同一件武具、位置大小一致；造型元素全部還在
- [ ] 沒有人、手、角色、子彈、魚

**金閃版分鏡**
- [ ] 四格姿勢與批 3 一致
- [ ] 閃點從第 1 格就有，路徑跟著招牌部位；第 4 格隨金光飄散
- [ ] 閃點是暖金，沒遮住武具

**追擊提示格（有做才驗）**
- [ ] 1920×1080，橫幅左武具右留空
- [ ] 文字是後製加的，字樣「追擊效果觸發」
