**道具 ICON 不生圖、走後製**：武具 ICON 就是整組縮圖，從 `weapon-design` 定稿直接裁（Tim 定案 2026-09-30；炮台翅膀、寵物線同規）；碎片版＝同圖左上疊碎片角標。定稿是單張 16:9 灰底，`pet-parts/scripts/item_icon.py` 直接吃、不用 `--half`／`--grid`。**碎片角標素材不進 repo**（線上 UI 素材裁切、kit 是公開 repo）：向主任拿，放本機 `skills/pet-parts/_工作暫存/fragment_badge.png`（已 gitignore），腳本用 `--badge <路徑>` 指路；沒有角標就只出主圖不出碎片版。

**不做**：武具欄外框與底色（依稀有度，UI 公版）、裝備中標籤、升星確認／升星畫面、洗鍊介面、能力顯示畫面、音效（§2.11）、稀有度徽章。追擊子彈本身沿用炮台線。

## 二、登場動畫分鏡

- **一張 2×2 四格**，16:9 灰底，格序**固定**：

| 格 | 內容 | 來源 |
|---|---|---|
| 1 | 中間出現 | §2.9 PM 註記「武具從中間出現」；有機關的武具畫初始收合態（盾：只有神獸頭） |
| 2 | 招牌動作 A | §2.9 該把流程第 2 步原文 |
| 3 | 招牌動作 B | §2.9 該把流程第 3 步原文 |
| 4 | 統一發光 | §2.9「武具背後散出金光 or 配合武具顏色光芒」；武具回到定位不動 |

- **動作照企劃逐字寫，不增不減**：企劃沒寫的動作、特效、角度一律不加（寵物線前科：虛弱自行加了「長弓放在地上」）。從零發想的武具照 mini 企劃的登場動畫概念拆，拆法先給使用者確認
- **四格是同一件武具**，位置與大小一致（正中央、約格高六成），只有姿態與特效變；提示詞**逐項點名要保留的造型元素**
- **不畫人、手、角色**；不畫子彈與魚（登場動畫是攻擊畫面的一段，但分鏡只看武具）
- 標籤由 `pet-parts/scripts/label_frames.py --cols 2 --rows 2` 加（「圖N＋這格在做什麼」），不寫秒數、不交給模型寫字；只畫一大張沒分格會被腳本擋下，重抽
- 每格接近 16:9（整張 16:9 切 2×2），武具高約六成；橫向武具（弩、扇）以寬度為準不被切到

## 三、金閃版分鏡（3 星以上）

- **同四格、同格序、同姿勢**，差別只有金色閃點：從第 1 格就有，星芒狀、大小不一、帶柔光、數量適中、不遮武具
- **閃點位置與飄動路徑依招牌部位**（§2.9 第 3 點「每個武具都是用金色閃點，但依不同武具動態調整閃點的位置和飄動路徑」）：

| 武具 | 閃點路徑 |
|---|---|
| 玄暝雙龍劍 | 繞著兩劍旋轉的軌跡，交叉時匯到交點 |
| 離火飛鳳扇 | 沿扇面旋轉軌跡拖出弧線 |
| 麒麟神機弩 | 跟著電光沿弩臂由內向外 |
| 震威伏煞盾 | 跟著鐵鍊由下而上 |

- 第 4 格金光擴散時閃點一起向外飄散
- 參考圖**直接用外觀定稿**：首跑實證四格姿勢與批 1 一致，不必等批 1 定稿，兩批可並行送
- 驗收：**四格對照批 1 姿勢要一致**——姿勢跑掉就是重畫了分鏡，不是加閃點

## 四、追擊提示格（選做）

- **使用者要才做**。§2.7〈武具追擊動畫〉：射出第一發子彈後，跳提示「左方顯示技能來源武具，右方文字『追擊效果觸發』，出現約 1 秒後消失」；「文字與底色配色依美術調整」
- 一張 16:9 灰底：中央偏上一條橫幅（深棕深藍暗底、淡金描邊），左 1/3 放武具定稿縮圖，右 2/3 留空
- **文字後製**：`fit_canvas.py --whole` 補成 1920×1080 後，用 PIL 加字（不另寫腳本，字型候選照 `label_frames.py` 的 `FONT_CANDIDATES`）：

```python
from PIL import Image, ImageDraw, ImageFont
img = Image.open("追擊提示.png").convert("RGB")
font = ImageFont.truetype("C:/Windows/Fonts/msjhbd.ttc", 96)
ImageDraw.Draw(img).text((1080, 460), "追擊效果觸發", font=font, fill=(255, 220, 120), anchor="lm")
img.save("追擊提示_文字.png")
```

  座標依橫幅實際位置調；文字色先用暖金，配色本來就「依美術調整」，示意即可
- 驗收：橫幅右側沒被模型塞裝飾；武具縮圖造型配色與定稿一致

## 五、共通

- **等 `weapon-design` 的定稿**才做：所有分鏡都以定稿為參考圖
- 畫風：分鏡跟本體一樣走「手遊 3D 道具模型的成品渲染」；追擊提示走 UI 示意
- 特效光不可畫成螢光綠或黃綠；金閃是暖金
- **不修改既有企劃**；三把「暫放」武具沒有美術需求時，分鏡只能照 §2.9 動畫概念做，列為缺件回報
- **不做兩階**：武具升星不改外觀，三個產出（一個選做）各一套；金閃版是分鏡的第二套，不是第二階

## 六、驗收清單

**登場動畫分鏡**
- [ ] 2×2 四格，格序＝中間出現／動作 A／動作 B／統一發光
- [ ] 動作 A、B 是企劃 §2.9 原文，沒有多加的動作或特效
- [ ] 四格同一件武具、位置大小一致；造型元素全部還在
- [ ] 沒有人、手、角色、子彈、魚

**金閃版分鏡**
- [ ] 四格姿勢與批 1 一致
- [ ] 閃點從第 1 格就有，路徑跟著招牌部位；第 4 格隨金光飄散
- [ ] 閃點是暖金，沒遮住武具

**追擊提示格（有做才驗）**
- [ ] 1920×1080，橫幅左武具右留空
- [ ] 文字是後製加的，字樣「追擊效果觸發」

**道具 ICON（後製）**
- [ ] 主圖 512；有角標才有碎片版，角標在左上
- [ ] 64px 認得出武具類型與主色
- [ ] 灰底去乾淨、主體沒被裁到、底板圓角完整
