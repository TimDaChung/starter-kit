# 產圖提示詞模板

> 改提示詞只改這個檔，`SKILL.md` 的流程不用動。
> 寫法沿用 pet-evolution 與 cannon 系列驗證過的原則：**給比例與倍數、不給形容詞**；裝飾照企劃逐項列，不刻意減。

---

## 一、外觀定稿圖

```
捕魚機遊戲的 Boss 角色設計圖，一張圖只畫一個階段。

畫面：16:9 橫式畫面，純灰色背景（無漸層、無地面、無文字、無 UI）。Boss 置中、畫得大而清楚，四周留白，任何部位都不能被畫面邊緣切到。

畫風：【畫風錨點，見第二節】。高飽和，主色 2–3 色＋金色點綴，輪廓清楚、剪影大塊。

Boss「【Boss名】【階段名】」：
概念：【企劃的概念】
配色：【企劃的配色】
造型：
【企劃造型條目逐條照抄（臉部／身體／尾巴／持有物…）】
姿勢：【企劃的姿勢；沒寫就寫「半側身，面朝【左／右】」】

【多階段的第二階以後，加這段：】
參考圖是這隻 Boss 的上一階段定稿。臉型、姿勢、朝向維持和參考圖相同，只做以下改變：【本階段的變化條目】。（階段間的大小差由 `fit_canvas.py --height` 控制，不寫進提示詞。）
```

---

## 二、畫風錨點

既有 Boss **沒有統一畫風**（見 `參考素材索引.md`），所以每隻 Boss 開工前要定一個錨點：

| 情況 | 寫法 |
|---|---|
| 模式 A，企劃有外觀圖 | 企劃圖當 `--reference`，提示詞寫「畫風與參考圖一致」 |
| 使用者指定某隻既有 Boss 的畫風 | 那隻的定稿圖當 `--reference`，並寫「畫風參考此圖，造型不要照抄」 |
| 都沒有 | 「高營收手遊的 2D Boss 立繪，精緻厚塗，光影層次分明」 |

⚠️ 用別隻 Boss 當畫風參考時，模型可能把那隻的造型元素帶進來——**每輪至少 2 張**，挑圖時要特別看。

---

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 不寫佔畫面幾 % | 實測寫了也不照做（55% 畫成 95% 和 65%）；**大小由 `fit_canvas.py` 保證**，提示詞只要「畫得大而清楚」，讓縮放時是縮小不是放大 |
| 「任何部位都不能被畫面邊緣切到」 | 模型傾向把主體畫滿，翅膀、尾巴常被切；被切了腳本救不回來 |
| 16:9 仍寫進提示詞 | 讓構圖接近橫式；**精準的 1920×1080 由腳本保證** |
| 一張只畫一個階段 | 多階段擠同一張會互相壓縮尺寸，比例就不準了 |
| 特效排除黃綠色 | 模型的固定偏誤（見 kit 的 `image-studio-共用須知.md`） |

## 三、絕招／技能 cut-in 特寫

外觀定稿當 `--reference`。**共用前言每招都一樣**，只換下面那段招式描述；一招一個提示詞檔。

```
捕魚機遊戲 Boss 放絕招時的 cut-in 特寫圖。

共用前言：
- 參考圖是這隻 Boss 的外觀定稿。造型、配色、部件與參考圖一致，畫風一致；只改表情、姿勢與特效。
- 16:9 橫式畫面。Boss 在畫面左側，約佔畫面寬度的六成；右側約四成是乾淨的留白（背景延伸、特效餘韻可以，不放主體），之後要在那裡疊標題字。
- 畫面上不能有任何文字、字母、數字、符號、招式名、對白框、UI。

招式「【招式名，只給你看，不要畫成字】」：
【這一招的動作：用哪個招牌部位、做什麼可見動作、特效長什麼樣、朝哪個方向】
【表情與氣勢：例「雙眼發光、張口怒吼」】
```

| 寫法 | 原因 |
|---|---|
| 共用前言＋每招一段 | 前言鎖畫風與構圖，各招只差動作；組員實測 4 招各 2 張都一次成功（未在 kit 實測） |
| 右側留白、不畫字 | **標題在簡報／引擎疊字**：AI 寫中文常錯字、缺筆，畫進圖就整張重來；留白讓疊字不壓到角色 |
| 招式名註明「不要畫成字」 | 提示詞裡出現的名稱，模型常會寫進畫面 |
