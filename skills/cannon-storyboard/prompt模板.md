## 模板本文

把 `【】` 依企劃替換，其餘原樣送出。

```
你是一位遊戲美術設計師。請繪製捕魚機遊戲「翅膀技能」的表演分鏡圖。

參考圖是這套裝的炮台與翅膀組合，四格裡的炮台都要照著它畫。

技能名稱：【企劃 2.3 的技能名】
整體設計：【企劃 2.3.A 的一句話概要】

版面要求：
a. 一張圖分成 4 格，排成 2 列 × 2 欄，格與格之間留出明顯間隔。
b. **每一格都是 16:9 的橫向畫面**（整張圖因此是 32:18）。
c. 背景是單一純色的中性灰，四格都一樣。不要畫海底、場景或任何背景細節。
d. 炮台的位置與大小（四格完全相同）：
   - **寬度只佔單格畫面寬的三分之一左右**，不要畫大。高度約佔畫面高的五分之二。
   - **左側要留白**：炮台的左邊緣距離畫面左緣，大約要空出畫面寬度的十分之一。**不要把它推到貼齊畫面左邊緣。**
   - 水平中心大約落在「畫面寬度四分之一再往右一點」的位置。
   - 底部貼齊畫面下緣（下半部可以被畫面邊緣切掉一點）。
e. 除了第 4 格的結算框以外，畫面上不要有任何文字、數字或 UI。

四格內容（由左至右、由上至下）：

- 第 1 格：攻擊起手式。炮台發動技能、把攻擊發射出去的那一刻。【填入企劃分鏡中「發射什麼」的描述】
- 第 2 格：攻擊展開並命中。【填入企劃分鏡中攻擊如何擴散、命中的描述】
- 第 3 格：攻擊結束，畫面上出現錢袋，正朝著左下角的炮台飛過去。
- 第 4 格：結算畫面。攻擊特效已經結束，畫面回復平靜。炮台的正上方跳出彩金結算框，結構如下：
    最下面是一個橫向的彩金數字框，框裡的數字寫「999,999,999」。
    數字框的正上方直接放著【翅膀名】的翅膀圖示——**就是翅膀本身，不要加圓形外框、不要做成獨立的圓形 icon**。
    「【技能名】」的技能名稱**直接壓在那片翅膀上面、與翅膀重疊**，翅膀從文字的後方露出來。
    也就是說，翅膀與文字是疊在一起的一組，整組放在數字框的正上方。

★ 攻擊範圍：【依稀有度填入下方對應句子】
```

## 攻擊範圍（依稀有度擇一填入）

**史詩級**：

```
★ 攻擊範圍（重要）：這個技能是史詩級，攻擊覆蓋「畫面的左半部」。
   攻擊特效要**填滿整個左半邊**——從畫面的左邊緣一路延伸到畫面正中線，上下也要撐開到接近畫面的上緣與下緣。
   **不要只在炮台正上方畫一小團特效**，那樣範圍太小了。
   畫面的右半部則保持乾淨的灰色背景，完全不要有特效。
```

**傳說級**：

```
★ 攻擊範圍（重要）：這個技能是傳說級，攻擊覆蓋「整個畫面」。
   攻擊特效要**填滿整張畫面**——左右兩側、上下都要撐滿，不留大片空白的灰色背景。
   **不要只在炮台正上方畫一小團特效**，那樣範圍太小了。
```

## 填寫要點

### 企劃分鏡怎麼分配到四格

企劃的分鏡數常與四格對不上，**以四格結構為準**把內容分配進去：

| 企劃分鏡數 | 分配方式 |
|---|---|
| 3 格（含結算） | 前 2 格 → 第 1、2 格；錢袋那段通常寫在攻擊格裡，抽出來當第 3 格；結算 → 第 4 格 |
| 4 格（含結算） | 大致一對一 |
| 5 格（含結算） | 前 4 格壓縮成 3 格（登場與蓄力併入第 1 格），結算 → 第 4 格 |

### 濾掉非畫面資訊

企劃的分鏡描述常夾雜實作指示，**不要寫進提示詞**：

- 「炸亮瞬間 client 震動畫面 1 秒」——程式行為，畫不出來
- 「噴 3 個金幣動畫，位置隨機，金幣飛往玩家」——只保留「錢袋飛向炮台」的畫面
- 「數量依美術設計」——直接省略

只留**看得見的畫面**。

## 本 skill 特有的前科

- **貼邊會連鎖毀掉第 4 格。** 只寫「炮台在左下角」，模型會把它推到貼齊畫面左緣；這麼一來第 4 格的彩金結算框沒有空間展開，也無法與炮台垂直對齊。**必須明寫左側留白約 10% 畫面寬**——這三個問題是同一個根因。

- **給位置還要給尺度。** 只寫「攻擊範圍是左半部」，模型會理解成「特效放在左半邊」而不是「填滿左半邊」——位置對了但範圍只有 1/4。要補上量化邊界（從左邊緣到正中線、上下撐開）與否定句（不要只畫一小團）。炮台比例也是同一個道理。

- **要模型做「不完整」的構圖，必須明講「不要做成什麼」。** 模型傾向把元素各自裝框、整齊排列：獎圈會被填滿中心、翅膀會被裝進圓形 icon。重疊、留空、切斷這類構圖都得加否定句。

- **加字不一定會排擠既有成果。** 加的若是「同一個規格的量化補充」（把攻擊範圍講得更精確），通常不會動到別處；加的若是「新增一個競爭的要求」（例如硬壓特效配色），才會從畫面品質扣。

- **「四格共用同一個場景、同一座炮台」必須明寫。** 不寫的話模型會讓炮台在各格間位移、變形，甚至消失。這條的地位等同 `cannon-wing` 的階段規則。

- **第 4 格是唯一允許出現文字的格。** 其他格若不明講「不要文字」，模型會自行加上假的 UI 與標籤。

- **16:9 要寫在每一格上，不能只說整張圖的比例。** 只寫「整張 32:18」，模型容易理解成四個正方形拼起來。

- **`slice.py` 要加 `--equal`。** 分鏡有背景色、沒有透明區域，預設的 alpha 投影法找不到切點；而且背景本身就是內容，不可裁到內容框。
