# 配件規格

> 各部件的版型、尺寸與驗收標準。改規格只改這個檔。
> 標「✅ 已實證」的條目由現行素材歸納，可信；標「⚠️ 待確認」的是推斷，第一次做要問使用者。

---

## 通用規則（所有配件）

1. **風格衍生自炮台翅膀定稿**：配色、材質、主題元素都要呼應定稿，不可自行發揮。這是配件唯一的風格來源。
2. **交付格式依部件而異，不要一概去背**：

   | 批 | 格式 | 依據 |
   |---|---|---|
   | 1 子彈＋彈紋 | **去背 PNG** | 6 套 `11xxxx.png` 實證 |
   | 2 獎圈 | **去背 PNG**，且**中央透空** | 使用者提供的範例圖實證 |
   | 3／4 雷射 | **灰底**，不去背 | 神諭樂章企劃示意圖實證 |

   共同點是都**不需要拼版合成**——不像 3×3 總覽圖要鋪底、加標籤、疊版位框。
3. **配色照企劃**：企劃每個部件都會寫「配色：…，配合炮台顏色」，照抄。
4. **rim light**：實裝背景是深藍海底，所有素材外緣要有外發光才跳得出來。

## 批 1：子彈 ＋ 一般彈紋 ＋ 專屬彈紋　✅ 已實證

現行素材：6 套的 `11xxxx.png`（檔名＝子彈 WID，例如炮台 `107009` → `117009.png`）。

### 版型

```
┌─────────────┬──────────────────┐
│             │  一般彈紋（圓形）  │
│ 子彈（橫向） ├──────────────────┤
│             │  專屬彈紋（圓形）  │
└─────────────┴──────────────────┘
```

### ⚠️ 關鍵做法：直式生成，事後程式轉向

**不要叫模型直接畫橫躺朝右的版型。** 實測過，彈紋被要求「橫躺朝右」時，圓形外框會被內容撐成橢圓，整個歪掉。

正確做法是**讓模型畫它最擅長的方向，轉向交給程式**：

```
      生成時（直式）                     轉 90° 後（交付版型）
┌──────────────────────┐        ┌─────────┬──────────────┐
│ [一般彈紋] [專屬彈紋] │        │         │  一般彈紋     │
│                      │  →     │  子彈→  ├──────────────┤
│       [子彈↑]         │        │         │  專屬彈紋     │
└──────────────────────┘        └─────────┴──────────────┘
```

- 生成時：**子彈直立朝上**放在下半部；**兩個彈紋正面、正圓**並排在上半部（左＝一般、右＝專屬）。
- 出圖後跑 `scripts/rotate.py` **順時針轉 90 度**，左右並排就自動變成右上／右下，子彈自動朝右。

```sh
python3 ~/.claude/skills/cannon-parts/scripts/rotate.py <素材.png> <轉向後.png>
```

### 交付版型

- **子彈在左，朝右**。實裝時子彈是朝上飛的，但素材圖一律橫躺朝右。
- **彈紋在右**，一般彈紋在上、專屬彈紋在下。
- **沒有專屬彈紋時只出兩件**（靈狐 `117009.png` 即為此例）：生成時彈紋只畫一個置於上方中央，轉向後即位於右側。

### 有無專屬彈紋

**看企劃有沒有 `2.4.B 專屬彈紋` 這一節**，不要看參考圖（參考圖可能是舊版、不完整）。傳說級通常有。

### 各件特徵

| 件 | 特徵 |
|---|---|
| 子彈 | 主體＋向後拖曳的尾焰／軌跡，整體呈水滴或箭鏃狀。主體通常是炮台的核心意象（靈狐＝狐火與狐紋、曜晶＝菱形晶體、智慧女神＝箭鏃） |
| 一般彈紋 | 圓形爆裂光球，中心是炮台的代表圖騰，外圈放射狀光芒 |
| 專屬彈紋 | **整體尺寸與一般彈紋相同**，不是放大的強化版。作法是沿用類似的設計語言，但**更換中間的內容**，或直接做一個全新設計。差異在內容與精緻度，不在體積 |

### 驗收

- [ ] 子彈朝右、位於左側
- [ ] 彈紋為圓形爆裂狀、位於右側
- [ ] **彈紋內的圖騰也朝右**（與子彈同向），不是正立的
- [ ] **專屬彈紋與一般彈紋尺寸相同**，差異在中間內容而非大小
- [ ] 配色與炮台翅膀定稿一致
- [ ] 去背乾淨，無底色卡與霧狀殘留

## 批 2：專屬獎圈　✅ 已實證

企劃位置：炮台頁 `2.4.C 專屬獎圈`（寫在炮台企劃裡，不是套裝企劃）。

### 版型

**單件、獨立一張、去背 PNG、橫向略寬**（左右裝飾外張所致）。沒有固定版型，就是一個獎圈本體。

**最重要的一條：中央必須透空。** 獎圈是套在獎勵物外圈的框，中央會疊在遊戲畫面上顯示內容，不可以是不透明的實心盤面。企劃寫「中心：星空底盤，**避免純黑**」講的就是這件事——可以有半透明的襯底，但不能擋住。

左右嚴格對稱。

企劃描述固定拆成四個部位，照抄即可：

| 部位 | 企劃怎麼寫 |
|---|---|
| 圓盤 | 外框材質與紋樣＋盤面（通常是漸層或星空） |
| 中心 | 底盤，**常明確要求「避免純黑」** |
| 四周裝飾 | 兩側外張的翼狀／獸狀裝飾、頂部冠飾、四方鑲嵌寶石、下緣垂墜、外圍飄散的主題元素 |
| 垂墜 | 有無、材質與數量 |

參考素材：各套資料夾的 `獎圈示意*.jpg`（2816×1536）是**炮飾 UI 介面內的展示畫面**，不是素材本身——左側那格大圖預覽的內容才是獎圈本體。

> 同一套可能有多種獎圈示意（公版、命運驚喜輪版、特殊版），做之前先確認要的是哪一種。

## 批 3：雷射子彈 ＋ 雷射彈紋（同一張）

企劃位置：套裝頁 `2.3 雷射特效`。**兩件畫在同一張圖上**，做法比照批 1。

### ⚠️ 雷射版是一般版的「光束化」，不是另一套設計

**圖案樣式要跟批 1 的一般子彈、一般彈紋是同一家族。** 因此出圖時要把**批 1 的成品也當參考圖**餵進去（連同炮台定稿一起），並在提示詞裡明講「延續第二張參考圖裡的子彈／彈紋」。

### 版型

```
┌──────────────────┐
│    [雷射彈紋]     │   ← 上方，圓環、簡化
│                  │
│   [雷射子彈 ↑]    │   ← 下方，光束直立、前端朝上
└──────────────────┘
```

**直式交付，不轉向**——這點與批 1 不同。批 1 的一般子彈要轉成橫躺朝右，雷射這批維持直式即可（2026-09-29 由使用者確認）。

### 雷射子彈

- 樣式沿用一般子彈，**整體拉長**成光束的表現方式。
- **只有前端，沒有末端**：前端是尖頭或圓頭的設計，**末端就是光束本身**——直接延伸出畫面或自然漸淡，**不可以在尾巴加第二個裝飾頭**。
- 灰底交付，不去背。

> ⚠️ 兩個曾犯的錯，都要避開：
> 1. 套裝企劃裡的示意圖是「光束中段的斜向特寫」，那只是在示意**材質紋理**，不是交付版型。照做會產出沒有前端的一段光束。
> 2. 只說「畫出最前端」而沒說末端怎麼處理，模型會畫成頭尾對稱的雙箭鏃。

### 雷射彈紋

- **設計要比一般彈紋「簡單」。** 企劃寫「可減少細節」是實作需求，不是偷懶——雷射彈紋在遊戲裡是**持續顯示**的（雷射一直打著），畫得太複雜會干擾畫面。
- 樣式仍要看得出跟一般彈紋同家族（中心圖騰、環體結構延續），但**元素精簡、細節收斂**。
- 完整圓環物件，灰底。

> ⚠️ 不要自作主張提高精緻度。2026-09-29 曾把規格寫成「精緻度與炮台翅膀同級，不因企劃寫『可減少細節』而草率」，方向完全相反，須重做。

### 最終貫穿光束

**不需要生成圖**——子彈加寬 1.5 倍，美術自行處理。
