# 配件規格

> 各部件的版型、尺寸與驗收標準。改規格只改這個檔。
> 標「✅ 已實證」的條目由現行素材歸納，可信；標「⚠️ 待確認」的是推斷，第一次做要問使用者。

---

## 通用規則（所有配件）

1. **風格衍生自炮台翅膀定稿**：配色、材質、主題元素都要呼應定稿，不可自行發揮。這是配件唯一的風格來源。
2. **交付格式依部件而異，不要一概去背**：

   | 批 | 格式 | 依據 |
   |---|---|---|
   | 1 子彈＋彈紋 | **去背 PNG** | 6 套 `11xxxx.png` 實證 |
   | 2 獎圈 | **去背 PNG**，且**中央透空** | 使用者提供的範例圖實證 |
   | 3／4 雷射 | **灰底**，不去背 | 神諭樂章企劃示意圖實證 |

   共同點是都**不需要拼版合成**——不像 3×3 總覽圖要鋪底、加標籤、疊版位框。
3. **配色照企劃**：企劃每個部件都會寫「配色：…，配合炮台顏色」，照抄。
4. **rim light**：實裝背景是深藍海底，所有素材外緣要有外發光才跳得出來。

## 批 1：子彈 ＋ 一般彈紋 ＋ 專屬彈紋　✅ 已實證

現行素材：6 套的 `11xxxx.png`（檔名＝子彈 WID，例如炮台 `107009` → `117009.png`）。

### 版型

```
┌─────────────┬──────────────────┐
│             │  一般彈紋（圓形）  │
│ 子彈（橫向） ├──────────────────┤
│             │  專屬彈紋（圓形）  │
└─────────────┴──────────────────┘
```

- **子彈在左，橫向、朝右**（朝向彈紋的方向）。6/6 皆如此。實裝時子彈是朝上飛的，但素材圖一律橫躺朝右。
- **彈紋在右，圓形爆裂狀**；一般彈紋在上、專屬彈紋在下。
- **沒有專屬彈紋時只出左＋右上兩件**（靈狐 `117009.png` 即為此例）。

### 有無專屬彈紋

**看企劃有沒有 `2.4.B 專屬彈紋` 這一節**，不要看參考圖（參考圖可能是舊版、不完整）。傳說級通常有。

### 各件特徵

| 件 | 特徵 |
|---|---|
| 子彈 | 主體＋向後拖曳的尾焰／軌跡，整體呈水滴或箭鏃狀。主體通常是炮台的核心意象（靈狐＝狐火與狐紋、曜晶＝菱形晶體、智慧女神＝箭鏃） |
| 一般彈紋 | 圓形爆裂光球，中心是炮台的代表圖騰，外圈放射狀光芒 |
| 專屬彈紋 | 同一構圖強化：光芒更多更長、加入第二色系、細節密度明顯高於一般彈紋 |

### 驗收

- [ ] 子彈朝右、位於左側
- [ ] 彈紋為圓形爆裂狀、位於右側
- [ ] 有專屬彈紋時，它明顯比一般彈紋華麗，但仍看得出是同一個設計
- [ ] 配色與炮台翅膀定稿一致
- [ ] 去背乾淨，無底色卡與霧狀殘留

## 批 2：專屬獎圈　✅ 已實證

企劃位置：炮台頁 `2.4.C 專屬獎圈`（寫在炮台企劃裡，不是套裝企劃）。

### 版型

**單件、獨立一張、去背 PNG、橫向略寬**（左右裝飾外張所致）。沒有固定版型，就是一個獎圈本體。

**最重要的一條：中央必須透空。** 獎圈是套在獎勵物外圈的框，中央會疊在遊戲畫面上顯示內容，不可以是不透明的實心盤面。企劃寫「中心：星空底盤，**避免純黑**」講的就是這件事——可以有半透明的襯底，但不能擋住。

左右嚴格對稱。

企劃描述固定拆成四個部位，照抄即可：

| 部位 | 企劃怎麼寫 |
|---|---|
| 圓盤 | 外框材質與紋樣＋盤面（通常是漸層或星空） |
| 中心 | 底盤，**常明確要求「避免純黑」** |
| 四周裝飾 | 兩側外張的翼狀／獸狀裝飾、頂部冠飾、四方鑲嵌寶石、下緣垂墜、外圍飄散的主題元素 |
| 垂墜 | 有無、材質與數量 |

參考素材：各套資料夾的 `獎圈示意*.jpg`（2816×1536）是**炮飾 UI 介面內的展示畫面**，不是素材本身——左側那格大圖預覽的內容才是獎圈本體。

> 同一套可能有多種獎圈示意（公版、命運驚喜輪版、特殊版），做之前先確認要的是哪一種。

## 批 3／4：雷射子彈、雷射彈紋　✅ 已實證

企劃位置：套裝頁 `2.3 雷射特效`。**兩件的版型完全不同，要分開出圖。**

### 批 3：雷射子彈（光弦束）

- **局部特寫，不是完整光束**：畫的是光束中間的一小段，**斜向**貫穿畫面（約 45°）。
- 雙色光束並行（主色＋副色），外圍纏繞捲曲光帶，光帶上散布主題元素（音符、星芒、光點）。
- 灰底、小尺寸。企劃會註明「可減少細節」，**不需要做到成品等級**。
- 實機形體是從炮口垂直向上、貫穿至畫面頂端的光束（由參考影片抽幀確認），但**素材只交付一段斜向特寫**。

### 批 4：雷射彈紋（爆裂光環）

- **完整圓環物件**，正方形畫布、灰底。
- 環狀光紋＋噴出的主題元素，外圈裝飾環繞，下緣可掛垂墜。
- 精緻度高（與炮台翅膀同級），不因企劃寫「可減少細節」而草率。

### 最終貫穿光束

**不需要生成圖**——子彈加寬 1.5 倍，美術自行處理。
