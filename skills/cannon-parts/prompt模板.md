# 配件產圖提示詞模板

> 改提示詞只改這個檔。
> **先讀 `cannon-wing/prompt模板.md` 的「為什麼這樣寫」前科區**——那些教訓（注意力零和、特效偏黃綠、平台偶發異常）在這裡完全適用，不重複寫。

---

## 最重要的手法：用炮台翅膀定稿當參考圖

配件的風格必須衍生自定稿。**把定稿的 3×3 總覽圖（或裁切出的 lv0 炮台那格）當 `--reference` 餵進去**，比在提示詞裡用文字描述風格可靠得多：

```sh
python3 ~/.claude/skills/image-studio/scripts/image-studio-client.py draw \
  --count 2 --prompt-file <prompt.txt> --reference <定稿圖.jpg> --output <輸出目錄>
```

文字只負責講「畫什麼」，風格交給參考圖。這樣提示詞能保持短，不必花篇幅描述配色與材質。

---

## 通用開頭（各批共用，接在批次段落前）

```
你是一位遊戲美術設計師。請依照美術企劃，繪製捕魚機遊戲的炮台配件素材。

共同要求：
a. 這是遊戲內資產素材（非場景插畫），部件輪廓清晰可讀。
b. 風格、配色與材質必須與參考圖的炮台翅膀一致，這是同一套裝的配件。
c. 精緻度達到高營收商業手遊水準：材質要有明確高光與暗部層次，不可平塗；外緣有一圈外發光（rim light），確保能從深色海底背景中跳出。
d. 配色只用【填入企劃配色】。特效不可畫成螢光綠或黃綠色。
e. 畫面乾淨：沒有文字、標籤、數字、邊框、圓形或橢圓形底色卡。
```

## 批 1：子彈 ＋ 一般彈紋 ＋ 專屬彈紋

```
【通用開頭】

美術企劃：
- 子彈：【企劃 2.3.A 的概念與描述】
- 一般彈紋：【企劃 2.4.A 的概念與描述】
- 專屬彈紋：【企劃 2.4.B 的概念與描述】

輸出規格：
一張圖，左右分區、背景單一純色：
- 左側：子彈。橫躺、朝向右方，主體在前、尾焰或軌跡向左後方拖曳。
- 右上：一般彈紋。圓形爆裂光球，中心是炮台的代表圖騰，外圈放射狀光芒。
- 右下：專屬彈紋。與一般彈紋同一個構圖，但光芒更多更長、細節密度明顯更高，一眼能分出階級差異。
三件之間留出明顯的空白間隔，不要重疊。
```

**沒有專屬彈紋時**（企劃無 `2.4.B`）：刪掉專屬彈紋那兩行，輸出規格改成「左側子彈、右側一般彈紋」兩件。

## 批 2：專屬獎圈

```
【通用開頭】

美術企劃：【企劃 2.4.C 的概念與描述，四個部位照抄】

輸出規格：
一張圖，畫面中央是一個獨立的獎圈，左右嚴格對稱，背景單一純色。

★ 最重要：獎圈的正中央必須是「空的」——中間留出一塊乾淨的圓形空間，不要畫任何東西進去，也不要用不透明的盤面把它填滿。這個圈是要套在別的東西外面用的，中央會顯示遊戲內容。企劃若寫「中心為某某底盤」，那只能是很淡的半透明襯底，不可遮擋。

環體與四周裝飾照企劃：外框材質與紋樣、兩側外張的裝飾、頂部冠飾、下方基座與寶石、外圍飄散的主題元素。
```

## 批 3：雷射子彈（光弦束）

```
【通用開頭】

美術企劃：【套裝企劃「雷射特效 - 子彈」的描述】

輸出規格：
一張圖，畫的是一道雷射光束「中間的一小段」的特寫，不是完整的光束，看不到頭也看不到尾。
光束以約 45 度斜向貫穿畫面，從左下延伸到右上。
雙色光束並行，外圍纏繞捲曲的光帶，光帶上散布主題元素。
背景單一純色。這是特效素材，結構可以簡單，重點在光感與流動方向。
```

輸出規格：

## 檢查

出圖後對照 `配件規格.md` 各批的驗收項目。最容易錯的三個：

1. **子彈朝向**——必須朝右，不是朝上或朝左
2. **獎圈中央被填滿**——這是最常見的錯誤，模型傾向把圓心畫滿
3. **交付格式搞混**——批 1／2 是去背 PNG（算圖要加 `--remove-background`），批 3／4 是灰底（**不要加**）
